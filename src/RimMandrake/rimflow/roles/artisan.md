# Artisan runner

Use MandrakeWorkflows `RUNNER=codex LOGS=<logs> bash ralph/loop.sh`, or `artisan/run_pass.py --runner codex --log <pass.jsonl>`; Claude remains the default and the claim/blind-judge lifecycle is unchanged.
See [runner options](runner_options.md) for environment, separate spend and Windows/WSL constraints; `artisan_now.py` is only an observer.
