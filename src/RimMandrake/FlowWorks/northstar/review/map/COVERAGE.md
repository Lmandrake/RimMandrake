# FlowWorks review map - feature coverage

Generated by `review_map.py --plan` from `review_map_coverage.py` (inventory read off disk; feature rules there). Do not hand-edit: change the rules or the stations and re-plan.

## Live build (one driver, the 22-mod `ratchet_pilot` tier, bridge held, game Playing)

```
python.exe src/RimMandrake/FlowWorks/review_map.py --build --fresh-map --save | tr -d '\r'
python.exe src/RimMandrake/FlowWorks/northstar/river_site.py | tr -d '\r'
python.exe src/RimMandrake/FlowWorks/review_map.py --rivers --build --save | tr -d '\r'
```

Expected runtime: about 12 minutes: the main map about 6 (fresh quicktest map ~1.5 min; the last build, 52 stations + 39 visuals, took 112 s; this one has 88 stations and ~250 more staging calls) plus its save; river_site.py about 3 to 4 (founding a colony on a river tile and generating its map); map R about 1 (25 terrain reads, ~60 placing calls) plus its save. Budget 20 minutes before calling it stuck.

Then `review_map.py --goto N` (or `--rivers --goto R3` on the river save) frames a station; `--labels` / `--rivers --labels` re-pin labels after a load.

## Which file is the live review map

`review_map.py` is the live map builder (`--plan/--build/--goto/--labels/--clear/--save`, and `--rivers` for map R in `review_map_rivers.py`). `human_review.py` is NOT a second map: it is the feature sheet (browser) and the status data layer `review_map.py` reads, so no consolidation was needed; the method doc's per-mod `human_review.py` builder role is `review_map.py` here.

## Rivers: a separate map

Every river mechanic reads the river current, which is copied from the map's river flow map, which only map generation writes. Painted river ground (the main map) has no current: a weir never pools, nothing is carried, a ferry rope never matters, a flood breaches nothing. So the main map keeps the bank works as LOOKS (stations `river_ford`, `river_works_looks`, `land_panning`, labelled so), and the mechanics are map R: `northstar/river_site.py` founds a colony on a river tile, then `review_map.py --rivers --build` anchors eight stations on that river's real crossings (`review_map_rivers.river_anchors`) and saves a second keeper. river_site.py vanishes the main map's colonists, so the main save is written first.
