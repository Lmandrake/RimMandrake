# Candidate skills this corpus could render into
(DUNGEON_DESIGN_RESEARCH_1 — sketches only; skills are authored in curation
sessions, never here.)

Four candidates. 1+2 are the load-bearing pair; 3+4 could fold into them if the
roster should stay small. [S#] = SOURCES.md.

## 1. `rimworld-dungeon-design` (authoring)
- **Trigger**: designing, laying out, or critiquing any hand-authored set-piece
  site map — vault, flesh dungeon, five-room minor site — before anything is
  built in-game.
- **Would encode**:
  - the topology grammar: loops-before-trees, ≥2 entrances, lock-key diagramming,
    foreshadow-payoff pairs, the concentric-ring and hub-and-wings templates
    ([S1][S2][S3][S4], map_templates.md laws);
  - the pacing skeleton: beat charts, sanctuary troughs, crescendo events,
    extraction finales, teach-test-twist, no-max-intensity finale ([S15]–[S18]);
  - RimWorld-specific constraints: turtle/killbox inversion, hauling economics
    (the exit shortcut), roof-collapse and power/temperature/darkness as native
    puzzle systems, what Anomaly's pocket maps already proved [S29][S30];
  - fairness rules: every lethal threat cued, ≥2 counterplays, no no-brainers
    ([S13], metrics B3/B4);
  - a pre-build checklist that runs the STATIC metrics (D1–D4, A1 estimate) on a
    paper layout before any bridge time is spent.

## 2. `experience-metrics` (evaluation)
- **Trigger**: any "is this fun / too long / too hard / too tedious" question
  about a map, site, encounter, or play session; before declaring any authored
  experience done; when designing verification for a BUILD item that ships an
  experience rather than a mechanism.
- **Would encode**: metrics.md operationalized —
  - the four measurement tiers (STATIC/SIM/JUDGE/ASK) and the rule that cheap
    tiers gate expensive ones;
  - the standard-crew protocol and the bridge clear-harness event logging
    (intensity curve, failure heatmap, downtime ratio, turtle test);
  - the JUDGE rubrics: GameFlow-derived review sheet, GEQ-derived post-visit
    probe, memorable-moment inventory ([S22]–[S25]);
  - the anti-metrics: backtracking cost, grind susceptibility, micromanagement
    load, with their thresholds ([S7][S13][S27]);
  - how to report: per-metric findings with the curve/heatmap artifact attached,
    never a single fun-score.

## 3. `set-piece-encounters` (population) — could fold into 1
- **Trigger**: populating an authored map with threats; designing any single
  fight, ambush, guardian room, or hold-out.
- **Would encode**: enemy-role composition (pressure/sniper/swarm/tank from the
  existing mechanoid/fleshbeast roster) [S19]; faction-triangle staging (garrison
  vs flesh, mid-war) [S9-Thracia]; crescendo-event pattern (player-triggered,
  prepared-for waves) [S15]; patrol scripting with randomized phase, authored
  route [S15]; the priced side-room ("machine") catalog [S12]; per-encounter
  fairness checklist.

## 4. `environmental-reveals` (narrative delivery) — could fold into rimworld-quests
- **Trigger**: authoring lore delivery inside a site — vignettes, staged scenes,
  reveal beats, memory-fragment loot.
- **Would encode**: vignette grammar (frozen-instant staging, one-image reveals,
  ambiguity-until-recontextualized for pre-reveal safety) [S21]; loot-as-
  narrative-fuel wiring into the cradle-memory channel; reveal-reliability
  verification (every viable route fires the beat — quest-signal silent-failure
  checks per the rimworld-quests skill); the register guard from
  ASSAILANT_FLESH_DUNGEON_1 (tyranny is revealed content only).
