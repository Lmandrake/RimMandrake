## AcousticScanner (C# logic: banding, pulse gate, cooldown, overlay)
Had: nothing (a validation.py only). Added: Source/Kernel/RM_AcousticKernel.cs (pure; behaviour-preserving except the edge fix below),
Source/SelfTest fuzz (band vs independent spec + invariants, gate exhaustive, clock lifecycle, ship exhaustive, units), 22 mutations
(mutate_acousticscanner_fuzz.py, all caught), lint_acousticscanner_defs.py (settings/floor/ranges/keyed/kernel-pure and all 62 shipped
payload patches: 239 targets), planted-defect selftest (23 plants). DLL rebuilt.
BUG FIXED: a band at the map edge was CLIPPED, so a hit in a map corner produced a 1x1 band = an exact hit, breaking the item's
"always banded, never exact" criterion. Edge blocks now slide inward and keep the full block size. (Found by writing the invariant
"every band is full block size" against the original; the fuzz spec encodes the fix.)
PROVISIONAL: StrongShare 0.6 / ModerateShare 0.25 (moved verbatim from the old literals, never tuned).
Design observation: when a map side equals the block size, the two edge blocks slide onto one whole-axis window (two bands, same rect,
different tiers). Harmless overlay overdraw; maps are >= 25 cells.
Generic tool fixes (benefit every mod): lint_mod_defs.py no longer reports test/fuzz project folders or default-glob csprojs as
"not in csproj", and takes require_xml / require_settings / instance_settings for mods without Defs or with instance settings fields.

## FlameStatues (C# logic: quality table, lit/shown/burning, fleck cadence, frame pick, fuel multiplier, never-run-out refill)
Had: validation.py only. Added: Source/Kernel/RM_FlameKernel.cs (pure), Source/SelfTest fuzz (quality, gate exhaustive, fleck cadence,
frame/jitter bounds incl. adversarial XOR inputs, fuel lifecycle), 24 mutations all caught (one mutant dropped as unreachable: the jitter

BUG FIXED: the fire-frame pick used Mathf.Abs(step ^ (id*391 + i*131)) % frames.Length; Abs(int.MinValue) is negative, so one draw in 2^32
indexed the frame array negatively and threw in PostDraw (every frame for that statue after). Masked to non-negative; same for the jitter index.
PROVISIONAL: the quality-to-size table 0.5/0.7/1/1.2/1.4/1.7/2 and the vent-offset bound (drawSize/2 + 0.25) in the lint.
Design observation: fuel-use multiplier is applied once at startup by mutating shared CompProperties_Refuelable (documented "after a restart"); fine, but
a mod that reads the def's rate before our static constructor runs sees the unscaled value.
