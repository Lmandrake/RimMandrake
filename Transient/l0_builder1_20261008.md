## GravshipLanding (one Harmony postfix, one setting; no Defs)

13 mutations all caught; structure lint (no Defs: harmony id == packageId, single postfix target, proof + postfix share the gate, About deps) with 13 planted defects.

Design observation for the owner: FloodUnfog spreads through every fogged non-fog-making cell, roofed or not, then unfogs the 8-neighbour border. So a roofed room joined
to open ground by any unwalled gap is revealed WITH the outdoors; only sealed roofed spaces stay fogged. The About text and the setting tooltip say "roofed interiors stay
hidden / fogged" without that qualifier. Not changed (About.xml is under mass edit by another agent); the unit test "an open door lets the flood into a roofed room" records it.

## HugeThings (C# logic: footprint arithmetic, trunk blocker reconcile, pawn hitbox)
Had: selftest_hugethings_footprint.py - a PYTHON MIRROR of FootprintMath.cs plus the Rot species table; it tests a copy, not the shipped code. Added: Source/Kernel/RM_FootprintKernel.cs
(pure; FootprintMath / CompHugeFootprint / HugeThingsApi now delegate - rect arithmetic, the whole blocker reconcile Plan(), cell eligibility), Source/SelfTest fuzz compiled against that
production kernel (math, trunk, pawn, plan over random worlds, growth/settings lifecycle, units), 30 mutations all caught (2 dropped as equivalent, reasons in the mutator),
lint_hugethings_defs.py (blocker def, slider ceilings == kernel clamp, ext defaults == kernel defaults, every plant extension in src/ sane + MayRequire-guarded with a >=9 probe,
csproj Compile Remove, kernel purity), 14 planted defects. The Python mirror's drift guard now reads the kernel file. DLL rebuilt.
BUG FIXED: plantTrunkScale / pawnHitboxScale are read from the settings file unclamped; the sliders stop at 1.5 but MaxRect (the cover used to re-link blockers after a load) is sized
for 1.5. A hand-edited value above that grew the trunk past MaxRect, so after the next load blockers outside it were never re-found (orphaned, and respawned duplicates on top). Found by
the fuzz drawing the setting from 0..4.5. Kernel now clamps the scale to 0..MaxTrunkScale. Also: the pawn slider ceiling was a bare 1.5 literal; both sliders now use the shared constant.
Also fixed: src csproj has default globbing, so a SelfTest folder would have compiled the net8 Exe into the mod DLL; added <Compile Remove="SelfTest\**"/>.
PROVISIONAL: minGrowthToBlock 0.25, hitboxFraction 0.6 (moved to named kernel constants), the MaxRect margin, the lint's trunk bounds 1..6 / 0..12.
Design observation: blockers are re-linked by scanning MaxRect each load; a trunk can only ever be reshaped by a refresh (every 2000 ticks or on a settings write), so a
player who builds beside a growing trunk sees the blocker appear up to ~2000 ticks late (cell stays open, never wipes a building - by design).
