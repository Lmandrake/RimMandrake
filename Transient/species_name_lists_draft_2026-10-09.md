## Appendix: wiring example
Existing pattern (`src/RimStarWars/StarWarsRaces/Defs/RulePackDefs/SW_NameMakers.xml`, e.g. `RSW_KoTOR_NamerBith`): a `RulePackDef` with `r_name` rules and `Rule_File` keywords pointing at text files under `Languages/English/Strings/RimMandrakeSWNames/SWX/<Species>/{First,Last}.txt`. The XenotypeDef then adds `<nameMaker>`. NOTE: the file is GENERATED by `src/RimMandrake/Utils/gen_races_mod.py`, so a real application edits the generator, not this XML.

Example (NOT applied) - Mon Calamari:

```xml
<RulePackDef>
  <defName>RSW_RimMandrakeNamerMonCalamari</defName>
  <rulePack>
    <rulesStrings>
      <li>r_name-&gt;[firstName] [lastName]</li>
      <li>firstName-&gt;[NameMonCalamari]</li>
      <li>lastName-&gt;[LastNameMonCalamari]</li>
    </rulesStrings>
    <rulesRaw>
      <li Class="Rule_File"><keyword>NameMonCalamari</keyword><path>RimMandrakeSWNames/SWX/MonCalamari/First</path></li>
      <li Class="Rule_File"><keyword>LastNameMonCalamari</keyword><path>RimMandrakeSWNames/SWX/MonCalamari/Last</path></li>
    </rulesRaw>
  </rulePack>
</RulePackDef>
<!-- First.txt: Aftab / Gial / Jesmin / Ocket / ...   Last.txt: Ackbar / Abaot / Alovar / ... (one per line) -->
<!-- XenotypeDef RSW_RimMandrakeMonCalamari: add <nameMaker>RSW_RimMandrakeNamerMonCalamari</nameMaker> -->
```

Single-name species (Geonosian, Togorian, Rakata): use `r_name->[firstName]` only. Cerean: `r_name->[a]-[b]-[c]` from a syllable file. Kaleesh: `r_name->[firstName] [particle] [lastName]` with `particle` in {jai, lij, san}.
