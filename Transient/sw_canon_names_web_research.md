# Star Wars canonical name research — WEB half

Owner ruling 2026-09-11: build a canon Star Wars name list, raiding retired donor mods
locally (separate agent) AND web research (this file), primarily Wookieepedia
(starwars.fandom.com). This is Transient scratch input for a follow-up merge into a
permanent `design/` reference doc — do not treat this file itself as final.

**Continuity note used throughout:** Star Wars has had two continuities since April
2014 — official **Canon** (films/TV/current books post-2014) and **Legends** (the
pre-2014 EU, now non-canon but still widely used by fans/mods and often richer in
detail). I mark **(Legends)** wherever a name/entry is Legends-only or where the
Wookieepedia article I used was the `/Legends` variant. Unmarked entries are Canon.
Where a topic exists in both continuities with different details, I note it.

Sourcing: Wookieepedia (starwars.fandom.com) pages/categories, reached via web search
snippets and (where fetchable) direct page fetch. I was not able to open the full
"Category:Desert creatures" listing page directly (fetch blocked, HTTP 402 on the
Fandom category page in this session) — that list is reconstructed from search-result
snippets, so treat the *bare list* as directional, but every creature actually written
up below was independently confirmed by its own search hit.
