- size: random size x exponent (and the edge values): divisor finite and exactly `size^exp`, 1 when size or exponent <= 0, `size * size` bit-exact at 2, monotone in size, and the third-party path composes to the flesh path within 0.2%; the stat part does nothing when off, for non-pawns, or at a size <= 0; anchors 25x rat, 1024x behemoth.
- flesh: hit / new-target / settings sequences: gates exhaustive (128), severity vs a double spec, fixed beats per-damage, strength is linear, accumulation never negative; anchors 250 / 10 / 0.0098 (rat / human / behemoth, the live-measured values).
- tiers: pawn and vehicle hits: machine / droid amount vs spec, flesh never takes the machine tier, a bigger machine never takes a bigger stun, shield break gates (16), vehicle stun ticks vs spec with each gate, a bigger footprint never stuns longer; anchors 1800 / 720 ticks and 80 on a 3x3.
