# Pyrelands — GPT pre-release hunt, triage (BENCH, 2026-10-15)

Five consults (gpt-6.1-sol, high), every one carrying the same design + debug context. The first fire-ecology consult
timed out at 575 s, so it was split into 1a/1b/1c. Every finding was checked against the code at HEAD 21abf9dd8e, and the
vanilla behaviour was read through RimSage (1.6 source). **No code was changed.** Answers: `answer*.md` beside this file.
Line numbers below are repo line numbers.

Verdicts: **CONFIRMED** = the code does what GPT said and it matters · **PLAUSIBLE** = the mechanism is real in the code,
but the impact needs the named check · **REJECTED** = wrong, ruled out of scope, or unreachable/documented.

## Rejected

| src | finding | why rejected |
|---|---|---|
| 1a-1 | Scorch-fruit `tickerType Normal` bypasses `TickLong`, so pods never grow | Wrong for 1.6: `Plant.TickInterval` calls `TickLong()` every 2000 ticks (RimSage `Plant.cs:801-808`), so a Normal-ticked plant still grows (default `growthInt 0.15`, `growDays 0.05`). Normal is what lets `CompRottable` run, and `scorchfruit_spoils_fast` PASSed live in r6. |
| 1b-4 | Density enforcer runs with the mechanics gate off | It re-asserts the BiomeDef's own XML values (16 / 9 d). The only extra is the regrow override, which is a test-profile setting. Nothing player-visible changes. |
| 1b-5 | `ambientAshHeavy` does not rebuild a live weather worker | Documented: the checkbox is labelled "Heavy drift (restart)" (`RM_PyrelandsMod.cs:465`). |
| 1b-10 | Legacy ash rungs under floors are not re-laid | Only pre-release internal fixtures can hold the retired rungs. No player save will. |
| 1c-1 | Second short circuit before the power-net rebuild drains protected batteries | Needs two shorts in the same tick before `PowerNetManager`'s deferred update. Shorts are single-culprit incidents, so this is unreachable in play. |
| 1c-3 | A failed yield placement eats the sand | `GenPlace.TryPlaceThing(Near)` searches a widening radius, so failure is unreachable in real play. |
| 2-2 | A burrowed grazer can still get Heatstroke | That is the ruling: one kind of heat, and vanilla Heatstroke applies. Ashwallow's comfortable max is 120 C, so only a sealed burning room reaches it. A burrow shelters from flame, not air temperature. |
| 2-4 | An in-flight burrow or ember job finishes after its setting is switched off | Bounded: the burrow ends when the fire clears or the cap is reached, and the ember is one drop. Finishing one job is graceful degradation; new jobs are gated. |
| 3-5 | Flame-harvest visit has no harvesting phase | Documented design (`IncidentWorker_FlameHarvest.cs` class doc): the sheet asks for the Tribes to be SEEN farming the fire; more would pre-empt ECONOMY_TRADE_SWEEP_1. The fire rite carries the real harvest. |
