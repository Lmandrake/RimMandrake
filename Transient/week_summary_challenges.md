12. **The ledger was sharded specifically so two windows could stop erasing each other's history.** `EVENTS_JSONL_SHARDING_1` split the single `events.jsonl` (a recurring rebase-conflict flashpoint) into one append-only file per seat; a same-seat conflict still needs manual git-plumbing surgery (hash-object → update-index → checkout-index) because normal edits to ledger files are hook-blocked by design.
13. **A "fixed" MapComponent was tested on a save that could never have run it.** A new MapComponent only activates at map creation (`FinalizeInit` runs once); reloading an older save to check a fix proved nothing, since that save was generated before the DLL carrying the fix even existed.
14. **The art daemon could wedge itself for up to 10 hours after its own quota reset**, because its idle-meter only refreshes by reading the newest Codex rollout file, and nothing writes a fresh rollout while it's busy refusing jobs on quota grounds — a true self-inflicted deadlock, fixed by forcing one throwaway probe call per worker to unstick it.

## New safety machinery (hooks/guards/stamps)

- **Shared-tree git hooks** (`block_shared_tree_merge.py` family): refuse a real merge, bare pull, whole-tree `reset --hard`/`checkout .`/`restore .`/pathless `stash`/`--autostash`/`clean -f` in the shared tree — direct response to the 215-file merge-erasure incident. Merges now happen only in a private worktree, published via `shared_sync.py`.
- **`DLL_SOURCE_STAMP_GUARD_1`** (`dll_source_stamp.py` + `.srchash` sidecars): every committed mod DLL must carry a hash of the source that built it, and a mismatch is refused on push — stops a merge from silently keeping one side's stale compiled binary.
- **`EVENTS_JSONL_SHARDING_1`**: per-seat ledger shards so two windows of different seats can no longer rebase-conflict on one ledger file.
- **`OWNER_SAID_PROVENANCE_GUARD_1`** (`block_forged_owner_said.py`): refuses an `--owner-said` quote that isn't provably in the transcript — imperfect (misfires post-`/clear`) but closes the "agent invents an owner quote" failure mode.
- **`code_review_status.py`'s GIT_TIMEOUT self-inflicted bug fixed**, then the file itself marked CLEAN — the standing dirty-code-review loop had been unable to check its own git status.
- **`validate_patch.py`** had at least two false-ERROR bugs fixed this window (PatchOperationInsert value-shape, texPath own-namespace) — the offline validator was crying wolf on legitimate patches.
- **`run_selftests.py`**: a selftest may now declare its own timeout (fixing `selftest_deployed_biome_refs.py`, which was reporting a false "0" on timeout instead of failing loudly).
- **`requeue_quota_failures.py`** + **artpipe self-heal fix**: quota-tripped art jobs go back to pending instead of terminal-failed; the daemon's wedge-after-reset bug (#14 above) got its own fix.
- **Handoff tooling hardened**: `handoff.py`'s self-referential WHOSE gate fixed; a new check needed because `--check` was passing on a *predecessor's* filled handoff, unable to tell a new session had started.
- **`validate-question-card.py`**: enforces question cards end in `?` and headers stay ≤12 chars — cost two real rewrites this week when tripped.
