## Fix

`.claude/hooks/block_forged_owner_said.py` `owner_texts()` now reads two more sources:
- a `user` line with `promptSource: "queued"`;
- an `attachment` of type `queued_command` with `commandMode: "prompt"`, provided `isMeta` is not set.

Both count only when `origin.kind == "human"`. The prompt can be a str or a list of blocks, and only
`text` blocks are read. Peer relays and task notifications still authorize nothing.
