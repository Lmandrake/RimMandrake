## Defects
- FIXED (real) clusterBlock change between 1 and above 1: `RebuildAllClustering` cleared the cluster state and only re-registered clusterable buildings, so on block 3 -> 1 every coated 1x1 building went DARK (never got a proxy of its own) and on 1 -> 3 each kept its own proxy AND joined a cluster (double light). Now every coated building is re-routed through the book (clustered or own, never both); fuzz plants the old behaviour and catches it.
- FIXED (real) Floors ignored the `maxCoats` setting: `CanAddFloorCoat` capped at the architecture ceiling 3 while things honour min(3, maxCoats). Floors now use the same `RM_DeepfireRules.CoatCap`. (Existing coats above a lowered cap are not stripped.)
- FIXED (latent) Steer chance at minimum skill 20: the vermilion slider reaches 20, and the SimpleCurve built from (20,0.5),(20,1.0) is degenerate, leaving a skill-20 cook with an unspecified 50% or 100%. Kernel returns 100% there.
- NOTE (design, not changed) Cluster radius uses `coatRadius[coats] + 1` for any group of 2+ cells even if the player set the radius very low; and the clustering block size is read live between a settings change and the rebuild (the mod always rebuilds on WriteSettings, so benign).
- NOTE the fuzz restricts furniture cost parameters to costFurnitureBase <= costFurnitureCap; if a player could set base above cap, cost of a multi-cell piece would be LOWER than a 1x1 (not checked against the slider ranges).
