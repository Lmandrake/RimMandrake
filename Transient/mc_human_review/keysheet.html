Gimme Some Slack — human review

Reviewing the per-build style design: the look is picked on the build button and stored on each piece. Stations 1–11 stand side by side in four looks. Default look (station 12 and the stations 13–33, which store no look): Scrapper; change it in Mod Settings › Default style. The game is paused, god mode on, clear weather, noon, Peaceful.

Everywhere: each build button opens a four-look menu (conduit adds the Modern colours: random mix, one colour per run, orange, green, brown, yellow, blue) and remembers your pick. 'Restyle this run' sits on any selected conduit, switch or pole. Joining two looks: the run with more conduit cells wins, a tie goes to the older run. Master switch OFF = vanilla conduit art. Unpause for motion.
