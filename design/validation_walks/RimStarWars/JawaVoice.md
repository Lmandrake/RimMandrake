# JawaVoice — validation walk
subject: src/RimStarWars/JawaVoice  (packageId `mandrake.rsw.jawavoice`, from About/About.xml)
deps: JPT.speakup (SpeakUp) — modDependencies; SpeakUp itself hard-requires Jaxe.Bubbles (Interaction Bubbles) per README.md; loadAfter also names JPT.speakup
list: minimal+SpeakUp (SpeakUp + its own Interaction Bubbles dependency; no assembly of its own — pure XML)
status-hint: pure-XML, assembly-free patch mod — for every SpeakUp InteractionDef it ADDS (never replaces) high-priority, identity-gated Jawaese rulesStrings lines, so Jawa pawns speak Jawaese and everyone else falls through to SpeakUp's untouched English (About/About.xml)

## must be true
- Every InteractionDef this mod patches gains four additional `logRulesInitiator/rulesStrings` entries per Jawaese line variant, gated `INITIATOR_faction==PlayerColony`, `INITIATOR_faction==PlayerTribe`, `INITIATOR_kind==RSW_Jawa`, `INITIATOR_kind==RSW_JawaTribal`, every one at `priority=250`.
- Nothing is replaced: every `PatchOperationAdd` only appends, so SpeakUp's own (lower-priority) English rulesStrings for the same InteractionDefs remain present and unmodified — a non-Jawa, non-player pawn still speaks English.
- Every add is wrapped in `PatchOperationConditional`, so a missing target InteractionDef or `rulesStrings` node is a silent no-op for that one operation, never a load error — and this means "the patch applied" can only be checked by reading the resulting def back, never by absence of a log line.
- Coverage spans all 11 `Patches/*.xml` files, 205 `PatchOperationConditional` blocks total (counted directly, 2026-09-08 — Ideology 15, Insults 3, CoreInteractions 2, Interactions 58, animals 1, chitchat_jokes 33, chitchat_thoughts 45, chitchat_weather 17, deeptalk 5, prisoners 21, romance 5), across weather, needs/thoughts, jokes, chitchat, deep talk, prisoners, romance, insults, ideology, animals and core interactions.
