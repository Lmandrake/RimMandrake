# Livestock — validation walk
subject: src/RimStarWars/Livestock  (packageId `mandrake.rsw.livestock`, from About/About.xml)
deps: sarg.alphabiomes (Alpha Biomes) — loadAfter only, needed solely for `Patches/ForsakenCrags_WildSpawns.xml` (targets `BiomeDef[defName="AB_RockyCrags"]`); everything else in this mod (both animal ThingDefs/PawnKindDefs, the karrask recipe/materials, the DamageDef/HediffDef pair, `CompLightAversion.cs`) needs only Ludeon.RimWorld
list: minimal for everything except the wild-spawn patch check; minimal+sarg.alphabiomes for that one
status-hint: two untameable Forsaken Crags predators (cindermare — kills by a cold-drain grip, not a bite; skarnix — flees lit ground via a C# comp) plus karrask, a tameable Jawa farm animal whose shed cures (vanilla `CompProperties_Shearable` + a plain bench `RecipeDef`) into a real armor Stuff (About/About.xml)

## must be true
- `RSW_Cindermare` and `RSW_Skarnix` (`Defs/ThingDefs_Animals/ThingDefs_ForsakenCrags.xml`) are both `Wildness 1.0` (untameable) and carry no head/mouth flavor — Cindermare kills via a `cold-drain grip` melee tool whose `extraMeleeDamages` applies `RSW_ColdDrainDamage`, a `DamageWorker_AddInjury` DamageDef whose `<hediff>` field is `RSW_ColdDrain` (`Defs/DamageDefs/DamageDefs_ColdDrain.xml`, `Defs/HediffDefs/HediffDefs_ColdDrain.xml`) — the wound record itself IS the cold-drain injury, not a separate mechanic layered on a bite.
- `RSW_Skarnix` carries `RimMandrake.StarWars.Livestock.CompProperties_LightAversion` (`fleeSearchRadius=10`, `fleeExpiryTicks=600`) — `CompLightAversion.CompTickRare()` forces a `Goto` job to the nearest reachable dark cell whenever `map.glowGrid.PsychGlowAt(pawn.Position) != PsychGlow.Dark`, with a 5x-`fleeExpiryTicks` cooldown afterward so the resumed job gets a real window before it can re-trigger (`Source/CompLightAversion.cs`).
- `RSW_Karrask` (`Defs/ThingDefs_Animals/ThingDefs_Karrask.xml`) is tameable farm stock (`Wildness 0.35`, `herdAnimal true`) whose vanilla `CompProperties_Shearable` produces `RSW_KarraskShedRaw` (a `ResourceBase` with deliberately NO `stuffProps` — mechanically inert, cannot be selected as Stuff) which the ordinary bench `RecipeDef RSW_CureKarraskPlate` (40 raw → 30 `RSW_KarraskPlate`, `HandTailoringBench`/`ElectricTailoringBench`, Crafting≥3) turns into `RSW_KarraskPlate`, a real `LeatherBase`-derived Stuff (`stuffProps/commonality 0.05`, armor/insulation `statBases`).
- `RSW_Cindermare`, `RSW_Skarnix` and `RSW_Karrask` each have a `PawnKindDef` with 3 `lifeStages`, every stage's `bodyGraphicData/texPath` pointing at the one real PNG under `Textures/Things/Pawn/Animal/<name>/<name>.png` shipped in this mod (`Defs/PawnKindDefs/PawnKindDefs_ForsakenCrags.xml`, `Defs/PawnKindDefs/PawnKindDefs_Karrask.xml`).
- `Patches/ForsakenCrags_WildSpawns.xml` wires `RSW_Cindermare` (0.04) and `RSW_Skarnix` (0.09) into `AB_RockyCrags`'s `wildAnimals` dictionary via `PatchOperationConditional` gated on the target node's own existence — without Alpha Biomes active this is a real silent no-op, not a load error, and neither creature spawns wild anywhere.
- The karrask ThingDef/RecipeDef pair are explicitly flagged in-file as `NOT live-verified this pass (offline defs-only build)` and `Not yet deployed/load-tested` — this walk is this mod's first load-time check.

## the walk

2. [D] def read-back: `DamageDef RSW_ColdDrainDamage` exists; `workerClass = DamageWorker_AddInjury`; `hediff = RSW_ColdDrain`; `defaultDamage = 1`.
3. [D] def read-back: `HediffDef RSW_ColdDrain` exists (`ParentName InjuryBase`); `hediffClass = Hediff_Injury`; `injuryProps/painPerSeverity = 0.018`.
4. [D] def read-back: `ThingDef RSW_Cindermare` → `statBases/Wildness = 1.0`; `tools` contains the `cold-drain grip` tool (`power 14`, `linkedBodyPartsGroup HeadAttackTool`) whose `extraMeleeDamages` entry is `def RSW_ColdDrainDamage, amount 6`.
