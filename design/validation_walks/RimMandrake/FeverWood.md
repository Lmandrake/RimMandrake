## anti-guessing notes
- RULED OUT: "the lash can be tested with one near and one far pawn at once" — `FindTarget` returns the FIRST pawn in range, so an out-of-range pawn can only be tested while it is the only candidate; the script runs the far arm first and adds the near pawn after (selftest break `lash_range_infinite`).
- RULED OUT: "the tank's escape chance is random, so it cannot be checked" — the per-hit chance is `clamp01(damageEscapeChancePerHit / max(0.01, sekkulaathEscapeRiskMultiplier))`, so a multiplier of 0.01 forces it to 1 and the check is deterministic (`RM_CompCapturedSpecimen.PostPostApplyDamage`).
- RULED OUT: "the sap-suckers refuse at random" — the design sheet forbids it and the comp is a cooldown gate (`RM_CompSapSuckerRefusal.TryRefuse`); the cooldown component fails if a second hit inside the window re-triggers it.
- RULED OUT: "the pool suppression is visible in `blockedUntilTick`" — that is private; the only readable sign is the `clouds and stills` message, which lives about 13 real seconds, so the script polls for it while the job runs and lets the first arm's message expire before the toggle-off arm.
- RULED OUT: "the ambient tentacle emergence can be checked on any quicktest map" — it needs `RUT_MapComponent_TheTenant.IsRegisteredWater`, which only the Fever Wood's scatter-pools genstep fills.
- RULED OUT: reading `<wildAnimals>` through `jawa/get_defs` — a non-public list it cannot serialise (Pyrelands, 2026-10-01); the suite uses `jawa/biome_probe`, which reads the runtime caches.
