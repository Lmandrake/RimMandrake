# Polish: a mod does not stand at his walk with in-game checks owed

A record, not a queue.
- While a change touches a check whose row still counts by an equal mod hash, each tick reads the walk folder again (about
  30 s of Windows reads for Pyrelands).
- A Pyrelands check names no C# file, so one C# change reruns all 40; `version/exercises.json` would narrow it.
