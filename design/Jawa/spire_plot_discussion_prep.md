# The Spire — plot-discussion prep for the campaign-function sitting

_Prep for the owner's dedicated sitting on the Ashfall Research Base's campaign
function. He ruled 2026-09-12 (`worldbuilding/ashfall_research_base.md` §6):
function NOT ruled, deliberately — "Not ready to resolve this yet, need a whole
plot discussion first (TBD)" — and chose "Dedicated sitting, I prep first."
This is that prep. Nothing here is a ruling; §3's shapes are OPTIONS stated
evenly, and anything marked *speculation* is exactly that._

**Design register only.** No defNames coined, no worldgen, no Force routes.
Sources are cited, not restated: `worldbuilding/ashfall_research_base.md`,
`worldbuilding/biomes/the_contagion.md`, `worldbuilding/biomes/the_rust_cathedral.md`,
`cathedral_concealment_arc_spec.md`, `tibanna_embargo_plot_spec.md`,
`canon.yml > helix_lineage / rust_cathedral / rakata.reclamation / antiquities`.

What is already free to proceed regardless of this sitting: the dungeon shell
and The Spire landmark (thin black needle, disc pad near the top, intermittently
visible through the Scald's mountain turbulence — owner verbatim, base doc §6).
What is blocked until this sitting rules: any quest, prize, or threat-clock
build.

---

## 1. The threads that MUST braid

Whatever function is chosen has to hold all six of these at once. Each is a
standing ruling; the function may arrange them, never contradict them.

**The reveal the base carries.** One line of plot only, owner's instruction
(`the_contagion.md` §8; base doc §2): the datafiles reveal the real
Helix–Assailant relationship — the splice claimed as descent, and the Overdrive
program itself: the Helix actively breeding the Contagion to be more robust and
productive, at the risk of unleashing it planet-wide. The splice's MOTIVE is now
also ruled (`canon.yml > helix_lineage.splice_motive`, 2026-09-12): it was a
key — Rakatan descent claimed as command authority over the Cathedral's
Rakatan-bound machines — and it works, or seems to: "they can walk past the
Mechanoids with impudence (or so it seems)," with "(or so it seems)"
load-bearing and the true mechanism deliberately un-canon. The function must
deliver this reveal without spending it early and without resolving what the
owner has held open (what the splice cost them waits for the flesh-dungeon
sitting).

**The Cathedral's hatred, and the player between them.** The Cathedral "HATES
the Helix from the moment they side with the Assailants, urging Forsaken
Sentinels to assault them" (`canon.yml > rust_cathedral.free_agent_src`), and
the base doc §2 makes it geographic: ⭐ the Ashfall Research Base IS that
siding, made concrete. Meanwhile the player is inside the concealment arc
(`cathedral_concealment_arc_spec.md`): the Cathedral hides from them at first,
missions against the Assailant register are the ruled proving ground, and
Cathedral Regard prices everything on the GM blackboard. A campaign function
for the Spire lands directly on that wiring — the base is the most
Assailant-register target on the planet — so the function must say how (or
whether) Regard sees action at the Spire.

**The Contagion escalation risk.** The UV cage is the planet's only quarantine
(`the_contagion.md` §3), and the Overdrive is an attempt to breed something the
cage cannot hold (base doc §1) — each trial generation "a little more robust, a
little less caged" (§2). That is a loaded gun on the mantel: the function must
decide whether it stays rhetorical (a horror the files describe) or mechanical
(a thing that advances and can fire). Note the hard frame either way: the map
is frozen and worldgen is banned, so "unleashed across the planet" can never be
repainted terrain — it can only be register, events, and (at most) a
campaign-catastrophe outcome in the style the Cathedral exposure ruling already
established (arc spec A3: a real, losable v1 outcome).

**The literacy-ladder gate.** RULED (base doc §6): the archive is encrypted;
the antiquities literacy ladder unlocks it. Seizing is unrestricted — READING
takes the ladder — so the truth lands in ladder order and can never front-run
the Reclamation or the flesh dungeon, and the gate must read as legible
in-fiction, not arbitrary. Consequence for the function: physical access to the
base and narrative payoff are DECOUPLED by ruling. Any shape that assumes
"raid the base → learn the truth" in one motion is already dead; every shape
below inherits seize-now, read-later.

**The Reclamation sequencing.** RULED (`canon.yml > rakata.reclamation_src`):
the Reclamation — every woken ancient plus the Helix, in concentrated assault —
is THE Helix hostility switch, it ends the Ascendant Ladder boon economy ("a
real price the player should see coming"), and the Helix's true-heart reveal
(`helix_lineage`) fires AFTER that event. So the function must not hand the
player a lever that flips the Helix hostile early through a side door, and must
not let the full reveal land before the Reclamation has run. The literacy
ladder is already the ruled instrument for the second half; the first half is
an open question (§2).

**A second clock beside the tibanna clock.** The embargo clock is the
campaign's ruled pacing spine (`tibanna_embargo_plot_spec.md` §5, T2 ruled
2026-09-12): calendar-driven, accelerated by the player's own traffic, visible
only through register, and two-ended — the player can break the meter, or the
Empire wins the drought. The Cathedral arc adds exposure pressure on the same
GM blackboard, also completable (A3). If the Spire becomes a third advancing
quantity, all three ride one blackboard and one register discipline (texture,
never gauges) — the question is not mechanism, it is attention: how many
independent dooms the campaign asks the player to track, and whether the
Spire's should run on calendar (like tibanna), on player action (like
exposure), or not run at all.

## 2. Tensions and open questions the function choice must answer

1. **Can the player STOP the Overdrive?** The program is written as an ongoing
   risk; nothing rules whether it is interruptible, and each answer costs
   something: stoppable makes the base a target and demands a resolution
   build; unstoppable-but-delayable makes it a clock; purely descriptive makes
   the horror rhetorical and risks the files reading as scenery.
2. **Does the Cathedral want the player to strike the Spire — and does Regard
   pay for it?** The concealment arc's missions are "against the Assailant
   register" and deniably sourced; the base is the Assailant siding made
   concrete. But the Cathedral survives by dullness and dreads local
   skirmishes — does it really commission an assault on a funded, fortified
   Helix compound, or only the quiet edges (interception, sabotage, specimen
   denial)? And pre-reveal, the player cannot be TOLD why the Cathedral cares
   (knowledge gate; ban on attributing agency before stage 3).
3. **What does acting against the Spire do to the player's Helix standing —
   before the Reclamation?** The Helix are a live boon economy (Ascendant
   Ladder; premium buyers of samples and unread antiquities) that the
   Reclamation is ruled to end. A function that has the player raiding the
   base early either burns that economy ahead of the ruled switch, or needs a
   fiction for why the Helix tolerate it (deniability, retrieval-not-war
   posture, the base's own secrecy). Unruled either way.
4. **Does seizing the archive itself have a Helix price?** Seize-any-time is
   ruled about the GATE, not about consequence. Is the seizure quiet
   (burglary), loud (assault), or gradated — and is that the same event as
   "the player has acted against the Overdrive" in question 3?
5. **What happens to the Contagion if the program completes — or if the base
   is destroyed?** The biome sheet owns everything ambient and its §6 bans
   (no green squares, no net-positive mutation, war-legacy split) are
   permanent; the map is frozen. Completion can only escalate register and
   events (spore blooms downwind, contagion-touched pressure, a catastrophe
   beat); destruction removes the observation-post sample economy and the
   genetic-lottery buyer — is the biome poorer, wilder, or unchanged?
   *Speculation: "open throttle" (§3) suggests the weapon does not need the
   Helix — destroying the base may stop the BREEDING while changing the biome
   itself not at all, which is a bleak and very on-register outcome.*
6. **Is The Spire enterable, and is it the dungeon?** The ruled landmark is a
   thin black needle with a disc pad; the drafted dungeon (base doc §4) is a
   concentric ground compound — containment ring, sample galleries, datafile
   core. Are these one structure (the needle IS the core), two (the needle a
   separate, possibly sealed tower above a ground compound), and does any
   interior differ before/after the reveal is read — a second visit that
   re-reads the same rooms, in the fractal-reading grammar the urns already
   ruled (`canon.yml > antiquities.fractal_reading_src`)?
7. **Does the function touch "(or so it seems)"?** The mechanism that lets the
   Helix walk past Mechanoids is deliberately not canon. A function whose
   prize is "the command key" would force that canon early — and would hand
   the player authority over the Cathedral's machines, colliding head-on with
   the concealment arc's entire premise. The sitting should decide whether
   the Spire's function is forbidden from resolving this, allowed to gesture
   at it, or is precisely where it resolves.
8. **Whose clock face does the player see?** All three candidate pressures
   (embargo, exposure, Overdrive) are register-only by standing discipline.
   If the Spire runs a clock, its register surface — Burn/Bloom rhythm
   changes, downwind spore-bloom frequency, Helix procurement tempo at the
   observation posts, contagion-touched severity — needs an owner pick,
   because the Contagion sheet owns all of those textures.
9. **What does the tibanna clock's endgame do to the Spire?** If the Empire
   wins the drought (T2), the planet is "more Imperial" — does Imperial
   consolidation ever reach a Helix bioweapons program, or are the two clocks
   ruled mutually deaf? (Mutually deaf is cheaper and currently the default;
   nothing couples them anywhere.)

## 3. Candidate shapes

Four named packages. None is recommended over another; each states what the
player does, how it ends, what it costs to build, what it forecloses, and what
it does to the other clocks. All four inherit the ruled invariants: landmark
and shell as ruled, seize-now/read-later archive, reveal in ladder order after
the Reclamation, Contagion §6 bans, no worldgen, no Force, game whole without
the Oracle.

### Shape A — "The Third Clock" (threat clock)

**What the player does:** the Overdrive advances — a GM-blackboard generation
counter, calendar-driven like the embargo, surfaced only through Contagion
register (blooms downwind, bolder escapes, procurement tempo). The player can
set it back by raids and sabotage on the base, and can end it by destroying
the core; ignoring it lets it complete.
**How it ends:** two-ended, on the T2 precedent — destroyed (program over,
archive seizable in the wreckage, Helix relationship priced) or completed (a
campaign-catastrophe-register outcome in the A3 grammar: a real, losable beat —
the cage fails somewhere, an event chain, not a terrain repaint).
**Build cost:** highest — a blackboard scalar plus escalation event ladder,
two resolution chains, and Contagion-sheet register work; every number
shadow-mode first.
**Forecloses:** the base as a stable, revisitable standing dungeon (a clock
consumes its own set-piece); leisurely pacing — a third doom competes for the
same player attention the embargo owns.
**Other clocks:** sits beside tibanna as a sibling (same grammar, risk of
doom fatigue); gives the Cathedral arc a natural Regard faucet (acting against
the Spire) but forces question 3's Helix-price answer immediately.

### Shape B — "The Archive Heist" (prize)

**What the player does:** the function IS the reveal's delivery vehicle: get
in, take the datafile core, get out — one designed infiltration/assault of the
drafted concentric dungeon, Burn-window tactics as taught by the biome. The
Overdrive stays what the files SAY, never a simulated program.
**How it ends:** it doesn't "end" — the heist completes, the encrypted archive
sits in the player's hold for the literacy ladder to open in ruled order, and
the base persists as a hostile fixed site.
**Build cost:** lowest — the dungeon build (owed anyway) plus datafile
content and one seizure beat; no new blackboard number.
**Forecloses:** player agency over the Overdrive (question 1 answered "no");
the escalation thread stays rhetorical, which risks the loaded gun on the
mantel never mattering; the Cathedral gets no Spire lever.
**Other clocks:** touches neither — cleanest separation, embargo and exposure
keep the whole pacing stage; the Spire becomes a place, not a pressure.

### Shape C — "The Cathedral's Errand" (quest line)

**What the player does:** the base becomes the concealment arc's
proving-ground made concrete: a deniably-sourced mission ladder (interception,
specimen denial, sabotage, culminating strike) rides the arc's existing
TOLERATED→VOUCHED machinery, each mission Regard-priced, the Cathedral never
named pre-reveal. The archive is seized along the way; the reveal arrives as
the ladder opens it — the player learns WHY they were sent only after they
went.
**How it ends:** with the culminating strike (the program broken as the quest
line's crown) or with the player declining the ladder — the base then simply
persists; no autonomous clock runs.
**Build cost:** medium — a mission chain on the arc's existing offer channels
and Regard wiring, plus timing guards (no full reveal before the Reclamation;
no premature Helix flip — the missions' deniability doing double duty as the
answer to question 3).
**Forecloses:** a Helix-neutral route to the base (the function belongs to
the Cathedral relationship — a player who never earns TOLERATED may never get
the thread); the Spire as anyone else's story; some of the dread of an
autonomous program, since it waits politely for the player's arc stage.
**Other clocks:** no new clock — it deepens the exposure/Regard economy
instead (strikes at the Spire are Regard up, and plausibly Heat up if loud);
the embargo is untouched; braids two existing systems rather than adding one.

### Shape D — "The Standing Wound" (persistent threat, no resolution)

**What the player does:** the base is a permanent event generator: Overdrive
escapes — specimen breakouts, downwind spore blooms, retrieval parties on the
player's ground ("the base does not raid; it retrieves") — at a pressure the
player suppresses by repeatable strikes that set the pressure back, never to
zero. The archive heist exists inside it as one raid among many.
**How it ends:** it doesn't, by design — the Overdrive is a chronic condition
of the dayside, outliving every other arc.
**Build cost:** medium — an event pool plus one pressure scalar; no
resolution chains at all, which is where the savings live.
**Forecloses:** resolution itself — and note the friction: the owner's
embargo law was "the situation must resolve soon; the clock genuinely runs
out; it is not scenery," and this shape deliberately builds the thing that
never resolves. Defensible (a wound is not a meter) but it must be chosen
with that law in view, not against it silently. Also forecloses "the player
stopped it" as a campaign memory.
**Other clocks:** competes with neither ending — but adds standing
background noise under both, which either enriches the register or muddies
it; the Cathedral can price suppression strikes (Regard) without any new
machinery.

*Hybrids are possible (B inside C; D degrading into A's completed end) but
each hybrid inherits both parents' costs; the sitting should pick a spine
first.*

## 4. What this sitting does NOT need to settle

Held elsewhere, on standing rulings: what the splice cost the Helix (flesh
dungeon sitting); the true mechanism behind "(or so it seems)" — unless
question 7 pulls it in deliberately; the exact tile and the landmark's live
placement (`CONTAGION_BIOME_PLACEMENT_1` + bridge sitting); KCSG templates,
datafile prose, cast and set-pieces (the owed dungeon sitting); every
Contagion ambient system (the biome sheet's).

## Sitting agenda

1. Can the player stop, delay, or only witness the Overdrive?
2. Should the Spire run its own advancing clock, ride the Cathedral's Regard
   economy, or carry no autonomous pressure at all?
3. Does the Cathedral direct the player at the Spire, and what does Regard pay
   for action there?
4. What is the Helix-relationship price of moving against the base before the
   Reclamation — and is seizing the archive the same offense as sabotaging the
   program?
5. If the program completes, is that a losable campaign-catastrophe beat in the
   A3 grammar, or something smaller?
6. If the base is destroyed, does the Contagion biome register any change, and
   does the sample/lottery economy die with it?
7. Is the needle itself enterable, and is it the datafile core or a structure
   above the drafted ground compound?
8. Should any interior or text differ before versus after the archive is read —
   a fractal second visit — or is one pass enough?
9. Is the Spire's function forbidden from, allowed near, or the designated home
   of resolving what actually lets the Helix walk past the Mechanoids?
10. Which of the four shapes (or which hybrid, or which fifth) is the spine —
    and what is its name in the campaign's own voice?
