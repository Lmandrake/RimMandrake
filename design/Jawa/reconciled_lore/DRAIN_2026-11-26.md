# Canon drain, 2026-11-26 — the record (CANON_DRAIN_1)

A dated record. Do not edit it after the drain; git holds the deleted sources.

## What this drain does

- Scope of group 1: the 14 undated `design/Jawa` docs whose first line was a SUPERSEDED banner that named
  `design/Jawa/reconciled_lore/NN` as the live version of their content. `reconciled_lore` became the authority at THE LORE SWITCH (841fe1b085,
  2026-08-30). Delete-don't-supersede (owner, 2026-09-09) says the dead source goes.
- Method (the owner's two blind arms): arm 1 (the bundle worker) writes, per source, the live facts that are absent
  from `reconciled_lore` and from the live design docs, and the stale lines it finds in `reconciled_lore`. Arm 1
  writes its list here BEFORE arm 2 answers. Arm 2 (GPT through `src/RimMandrake/Utils/gpt_consult.py`) gets the same
  sources and the same question, and never sees arm 1's list. The owner's rule is "cut only where both arms
  agree", so no fact that either arm calls live is lost. A fact that both arms name is folded into its live home. A
  fact that only one arm names is copied verbatim into "Disputed" below, with the arm that named it: this record keeps
  it, and canon does not take it without a second arm. Then the source is deleted, and the references in undated live
  docs are repaired. Dated records keep their citations.
- A stale line in `reconciled_lore` that an arm names is fixed only after the worker reads the cited live text.
- "Live" means: still true under the rulings of today. A proposal that was never ruled is not a live fact, and git
  keeps it.
