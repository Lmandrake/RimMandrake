# Next version, switched off

These are Designer version-allocation calls under this cleansing brief. Prior commissioning is preserved; no retirement is enacted and no built source/def is deleted. Default OFF includes producer/menu suppression, not just a patch guard. Existing animal species stay on their rosters. Each present built extra has its own OFF/ON ticket; absent/unknown behavior has a later-spec contract.
