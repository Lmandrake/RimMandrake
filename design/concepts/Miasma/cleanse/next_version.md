# Next version and retirement recommendations

These are Designer scope decisions. Deferred and retirement-candidate active behaviours default off under labelled controls. Existing defs, source and assets remain available. The existing pollination cut is recorded, with no new restoration work. Worldgen remains permanently forbidden.

### legacy_world_worker — Recommended retirement

Existing climate/river seeded world scoring and rarity slider. Recorded as built legacy code, excluded from the player promise by the permanent no-worldgen ruling.

Designer decision. Designer recommends disabling the legacy scorer and removing its player setting because worldgen is permanently forbidden. This capability has no next-version destination. Ticket T10.

### creche_despoil_memory — Recommended retirement

Anchored mother's death marks site despoiled and registers a timed map-wide manhunter/frenzied-animals chance multiplier, with saved state and settings gate.

Designer decision. Designer recommends retiring the map-wide extra manhunter lottery. It duplicates ordinary threat incidents and can punish the mother’s natural death, fighting the nursery payoff. Keep direct local defence and record consequences. Ticket T8.

### rot_research — Next version, switched off

One-shot current-meter/loam placement on new Miasma maps; analysis unlocks decay-cell research requiring Electricity.

Designer decision. A found-meter research sequence is an independent industrial progression. The nursery can run completely without it. Ticket T1.

### decay_power — Next version, switched off

Refuelable 2x2 generator: FoodRaw feed filter, configurable fuel target, fullness-dependent 600 W base output times setting, zero empty/off, lifetime digestion tracking. Built raw-food feeding falls short of the promised rot stream.

Designer decision. Rot electricity is the runner-up signature, an independent power economy. Ticket T21.

### spent_cell_bed — Next version, switched off

After observed lifetime consumption, generator consumes residual fuel and becomes a rotting bed preserving position/rotation/faction; saved digestion.

Designer decision. Industrial lifetime conversion belongs with deferred rot power. Ticket T22.

### corpse_disposal — Next version, switched off

Rare-ticking corpse storage, per-body clock, gear stripping, body-size bone stacks and named humanlike skull if head exists; progress/target saved; off keeps storage but suspends processing.

Designer decision. Corpse processing is an independent colony utility. Ticket T2.

### cuisine_bed_yield — Next version, switched off

Cuisine patches the spent bed with a vanilla CompSpawner yielding marsh fungus, a raw cooking ingredient; absent Cuisine leaves free bed without this food yield.

Designer decision. Food production in a spent generator adds another economy beyond ordinary biome life. Ticket T3.

### attar_production — Next version, switched off

Silt + raw salt recipe, luxury attar and still; runtime recipe availability and queued-bill start gate follow attar setting.

### attar_glaze — Next version, switched off

### attar_balm — Recommended retirement

Ordered pawn job uses one attar to reduce first permanent injury's severity; fresh wounds excluded. This is implemented as injury modification, so cosmetic-only scope needs verification.

Designer decision. Designer recommends retiring the current injury-severity balm because it changes health and conflicts with the cosmetic-only, no-medicine boundary. Cosmetic attar remains a next-version possibility. Ticket T5.

### flotsam_initial_seed — Next version, switched off
