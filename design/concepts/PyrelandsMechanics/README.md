# PyrelandsMechanics: Pyrelands 0.2.0 material

This record is **not a mod of its own and not a version of its own.** By card, 2026-11-13: "One mod, Tribes next version". Pyrelands is one mod (`src/RimMandrake/Pyrelands`, `mandrake.rm.pyrelands`, design `design/concepts/Pyrelands`) with one Design Version line. Pyrelands 0.1.0 is the biome alone. The Deep Desert Tribes designed here (the fire rite, the visit, the fruit defence) are Pyrelands 0.2.0, design kept as written. The files in `version/` were entered on 2026-11-13 as "PyrelandsMechanics 0.1.0" and relabelled the same day; `version/VERSION.json` holds the state.

The Tribes code that already exists ships in a separate package, `mandrake.rut.pyrelandsmechanics` (`src/RimUtinni/PyrelandsMechanics`), and must switch off cleanly for Pyrelands 0.1.0.
