# Next version and recommended retirements

All dispositions are Designer proposals. Reversible moved features default off and are labelled next version. A retirement recommendation awaits the owner. Automated planetary placement is already forbidden by standing ruling, so it has no later enabled version. Deferred owner-set semantics, accepted waivers and roster placements remain binding. Each present row has its own containment ticket. Unknown implementation needs the spec/integration task named by its census row.

### BiomeWorker and tunable cold/dry/elevation scoring are still compiled; spontaneous planetary placement is code present, outside the standing no-worldgen scope.

Recommended retirement. planet_scoring is the census entry.

Designer decision. Recommend retiring automated planetary placement under the standing worldgen ban. It is permanently out of scope, including the next version. Preserve reference-compatible inert stubs if needed. Work is T1.
