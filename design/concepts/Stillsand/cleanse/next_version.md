# Deferred features and recommended retirements

All dispositions are this Designer's proposal, Design Version 0.1.0. Next version means switched off, including in the campaign tier. Code and defs stay. No retirement is enacted. Historical cuts remain absent. Basic roster membership is unchanged.


- **Short-lived bloom after a pour or gale — Next version, off.**
  delegated: An event-only bloom adds a second renewal cycle; sparse ordinary flora already supplies life. Ticket: T_HOURBLOOM.

- **Water-fuelled swimmer lure and Groundcaller binding — Next version, off.**
  delegated: A bespoke lure/wetting building is not needed to cross, secure a cave or resupply. Ticket: T_THUMPER.

- **Coarse local buried-motion instrument — Next version, off.**
  delegated: Rumble and visible wakes already make natural danger readable; this is an additional tool. Ticket: T_GEOPHONE.

- **Blood-woken stripping swarm — Next version, off.**
  delegated: Event-spawned blood cleanup is a separate feedback loop, not ordinary wild roster life. Ticket: T_ZUURRIK.

- **Sand-buster tunnel-to-mound incident — Next version, off.**
  delegated: Infestation is an independent threat chain; the cave residents already make securing meaningful. Ticket: T_ERUPTION.

- **Spreading ruukka/oorrik brood mound — Next version, off.**
  delegated: Hive growth duplicates a vanilla infestation system and is independent of the expedition signature. Ticket: T_BROOD.

- **Warned Muurrok visit, body take and dive — Next version, off.**
  delegated: Ambient giants satisfy the giant crossing; a scripted hunt/arrival/departure chain is another signature. Ticket: T_LEVIATHAN.

- **Muurrok reflected-sun attack and crest product — Next version, off.**
