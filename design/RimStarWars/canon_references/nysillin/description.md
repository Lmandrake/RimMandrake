# Nysillin (plant)

**defName**: `RSW_Plant_Nysyllin_Wild` (label "wild nysyllin plant"; canon spellings "nysillin", "nysillim")

## Sourced text (Wookieepedia)
### Canon — https://starwars.fandom.com/wiki/Nysillin

A red healing herb, a common crop plant across the galaxy, a "universal cure-all" for any species, so valuable it was called a miracle cure (rumoured to derive from the Living Force). Seen in The Clone Wars "Bounty Hunters", farmed by the Felucian village Akira. Infobox: class Herb, origin Felucia, colour **red**. After the Clone Wars a spice made from nysillin extract raised its value. (A Legends page, Nysillin/Legends, also exists; not read.)
