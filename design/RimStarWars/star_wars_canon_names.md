# Star Wars canon name reference

A lookup reference of real Star Wars proper nouns, merged from a local-disk raid
(active mods, retired donor mods still cached, this repo's own docs/git history)
and web research (Wookieepedia). Ordered 2026-09-11, owner verbatim: *"Right now
start making a canon Star Wars name list. Raid the past mods to build it even the
donors we've retired. Additional web searches can add to it easily especially
those on wookiepedia."*

**Purpose**: tell real Star Wars canon apart from campaign-original invention, so a
future author doesn't (a) invent a name that collides with real canon, or (b) cite
something as canon that is actually a donor-mod relabel. **This doc is a reference,
not a design decision** — it compiles what two prior research passes found; it does
not rule on anything not already ruled elsewhere.

**Continuity marking**: Star Wars has two continuities since April 2014 — **Canon**
(films/TV/current books) and **Legends** (pre-2014 EU, non-canon but still widely
used by fans/mods and often richer in detail). Unmarked entries below are Canon;
`(Legends)` marks a Legends-only entry or fact.

**Provenance codes** (local raid, `Transient/sw_canon_names_local_raid.md` and its
four detail files, now aged out of Transient — see that doc's own §"Mod/source
coverage" for exactly what was and wasn't checked):
- **A** = active first-party "mandrake" mods on disk
- **B** = active third-party Workshop mods
- **C** = retired/donor mods (cached on disk, no longer active)
- **D** = this repo's own docs/git history
- **Wookieepedia** = web research pass (`Transient/sw_canon_names_web_research.md`), citing starwars.fandom.com

Spelling: where the two source passes disagreed, Wookieepedia's spelling wins
(better-sourced primary reference); a live ThingDef/XenotypeDef defName from the
local raid is otherwise treated as authoritative for how a name is already spelled
**on disk** today (calling out the difference where it's non-trivial).

### Already-ruled campaign canon-identity decisions (do not re-litigate here — cite, don't restate)

These are settled elsewhere; this doc only indexes them so it doesn't accidentally
contradict a standing ruling:

- **Galactic Empire = the vanilla `Empire` FactionDef**, patched not replaced —
  `design/Jawa/worldbuilding/EMPIRE_GAP_AUDIT.md` (owner, 2026-08-20). `Empire` and
  its six `Empire_*` PawnKind defNames are load-bearing.
- **The frozen "Ancients" sleepers ARE the Rakata** (endonym; called "the
  Forgotten"/"the Forsaken" by modern people) — a canon-identity ruling, not a
  reskin. `design/Jawa/worldbuilding/ANCIENTS_AS_RAKATA_SPEC.md` (owner,
  2026-08-20/2026-08-29).
- **"Iconic Star Wars status protects completely"** — a bantha that reads as a
  bantha is the campaign working, not failing; SW icons are exempt from the
  Earth-animal-recognizability cut rule. `design/Jawa/worldbuilding/
  creature_recognizability_rule.md` (owner, 2026-09-05).
- **`art: "improve"` semantics**: SW-named creatures keep canon identity; non-SW
  names are free to be reimagined. `infrastructure/artpipe/README.md` (owner,
  2026-09-11).
- **Hutt Cartel (`Jawa_HuttCartel`)** — an AUTHORED faction built around genuine
  Hutt lore, not a reskin. Ideo "the Reckoning of Debts."
- **Rebel Alliance** — appears via the Outer Rim donor mod; ruled near-lore/OK, not
  separately authored.
- **Geonosian Foundry Hive** — campaign faction built on the real species/world;
  owner ruling: "the Empire sterilised their species... every one here is a
  refugee."
- **`RSW_Yobshrimp` was explicitly renamed AWAY** from its SW-echoing name to the
  invented **FeatherFeel** (owner-mandated, `ART_REGEN_WAVE5` item) — despite
  "Yobshrimp" itself being a real canon creature name (see master bestiary list
  above), the campaign chose not to use the SW-adjacent name for this pawn.
- **"The Kindled" is an invented (non-SW) mechanoid concept** and has never been
  made — flagged only so it isn't mistaken for a Star Wars proper noun.

## Known issues (real bugs/traps this raid surfaced — not just names)

1. **The live lightsaber-name generator is NOT Star Wars.**
   `Armoury/Defs/Absorbed_KotorWeapons/ThingDefs_Weapons/
   Absorbed_KotorWeapons_lightsabernames.xml` (RulePackDef
   `NamerWeaponLightsaber`) has an entire name table of **Final Fantasy VI**
   character/esper names (Terra, Kefka, Shiva, Bahamut, Cait Sith, Ragnarok,
   Bismarck, etc.) — a leftover donor template currently wired to generate
   in-game lightsaber names for this campaign. This is a real live-gameplay-text
   bug. **As of this writing (2026-09-11), `rimflow next --seat FOUNDRY` shows no
   claimed or queued item against this file** — check again before fixing it, but
   it is not currently known to be someone else's in-flight work.
2. **`SWBestiary` (first-party mod) secretly carries non-SW content under an SW
   name**: absorbed "Jurassic Rimworld" dinosaurs (Diplocaulus, Segnosaurus,
   Platyhystrix, Protovermes, Protosolpuga, Baseopsis, Termitotron,
   Holcorobeus — flavor text literally styled "INGEN INTERNAL CASE FILE" /
   "BIOSYN"), plus ~70 absorbed BiomesTeam cave/biome creatures (Pod Worm, Royal
   Rhino Beetle, Yooka, Maligoat, Fleece Spider, Basilisk, etc.) — zero Star Wars
   content despite the mod's name. **"Lives in SWBestiary" is not itself proof of
   SW-canon status** — check the individual creature, not the mod name.
3. **The "Horax" naming collision.** This campaign's `ART_REGEN_WAVE1` item labels
   "Horax" (a creature in the master bestiary list above) a genuine SW-canon
   "redo" creature. This is a **different thing** from **`HoraxCult`**, the
   vanilla RimWorld Anomaly DLC faction — already explicitly ruled out-of-scope/
   not Star Wars by `design/Jawa/donor_proper_noun_backlog.md`. Verify "Horax"
   independently before treating it as settled canon; the two names are easy to
   conflate.
4. **`det.venators`** (active third-party mod) echoes the canon Venator-class
   Star Destroyer in name only — its actual content is a generic
   paralysis-focused human xenotype, unrelated. The same "author-initials, not
   SW" pattern applies to all five `det.*` xenotype mods and the two
   `det.epochs*` decor mods, plus `teiwaz.*`, `xylthixlm.races.*`,
   `karew.orcclan`, `gravtide.mod`, `chezhou.creature.sandworm`,
   `vanillaracesexpanded.starjack` — all checked and ruled NOT Star Wars despite
   sounding like it.
5. **`Sov.Sith` (retired mod, "Rimwars:Pureblood Xenotype")** never actually says
   "Sith" anywhere in its own XenotypeDef label/description — it's a generic
   crimson-skinned xenohuman. Don't cite this mod as proof a "Sith Pureblood"
   xenotype was ever explicitly authored on disk; only the flavor (crimson skin,
   bone ridges, psychic sensitivity) matches.
6. **`RSW_Yobshrimp` → FeatherFeel**: see the canon-identity rulings list above —
   the campaign deliberately renamed AWAY from an available SW-echoing name.
   Don't "fix" FeatherFeel back to an SW name without re-checking that ruling.
7. **`killathon.artificialbeings.syncore`** (retired) has an unresolved
   donor-header mismatch: the repo's dependency chain treats it as a separate
   "SynCore" mod, but the Workshop folder it should own
   (`Killathon.ArtificialBeings`, Workshop id 3288463094) self-declares
   packageId `Killathon.ArtificialBeings` with no `.syncore` suffix — no folder
   on disk actually declares the `.syncore` packageId. Name recovered only from
   `infrastructure/state/items/DROID_RETIRE_ABF_SYNCORE_1.md`.
