## Claude

Both items are closed. The last code commit is `e851961457`, and it is not deployed to ArchBig.

**The menu.** Each conduit cell, switch, pole, bracket and floor lamp now has one "Restyle..." button. It asks how far to reach first, then which look:
- This item
- All connected (8 pieces, 1 lamp)
- All on map (16 pieces, 2 lamps you own)

I didn't use a right-click menu. RimWorld's pop-up menus can't hold sub-menus, and a hidden right-click mode is the same kind of surprise you hit. Asking every time, with the piece count, means nothing is unexpected. "All on map" only touches your own things; in god mode it reaches every faction. The separate "DEV: switch ALL to..." button is gone because "All on map" does its job.

**Runs that hold more than one look** (written into the mod's design text before building):
1. Joining two runs still repaints the smaller one, but only when both runs have a single look. A mixed run is never repainted.
2. A piece built onto a mixed run takes the look of the piece it touches.
3. "All connected" repaints the whole run, so it has one look again.
4. A lamp follows "All connected" if it wears any look the run had before, or none.
5. A run painted "one colour per run" has one look, so it behaves exactly as before.

**Gust** is now the default overhead sway. Pendulum and Rope are still in Mod Settings.
