**The problem, briefly.** Each seat window gets a 10 GB memory pen, and Claude lives inside it with everything it runs. Two things keep filling the pen until the kernel kills whatever is biggest, and that is often Claude itself:
1. **Copies of the repo written into `/tmp`.** `/tmp` is a RAM disk, so a 12 GB clone there is 12 GB of RAM. That memory stays charged to the seat even after the process that wrote it dies. This has caused six deaths since 10-01, and Claude was killed in five of them. Two written lessons didn't stop it.
2. **The test suite running 16 tests at once inside the same pen.** Some tests use up to 5 GB each.

**What I checked this morning:**
- **The built-in Claude cap is real but fragile.** The installed Claude Code (2.1.286) has `CLAUDE_CODE_TOOL_MEMORY_LIMIT`: it puts every command Claude runs into a sub-pen, so a runaway command dies and Claude survives. To do that it has to create a child cgroup inside the seat's scope, and our scopes aren't set up to allow that (no `Delegate=yes`). When setup fails it switches itself off with a log line only, so the seat would look protected while being exactly as unprotected as now. I won't count it as working until a planted 7 GB memory bomb dies and Claude lives.
- **One test at a time is slow.** Dropping the suite from 16 workers to 1 makes a full run about **44 minutes instead of under 4** (summed timings MEASURED from `/tmp/selftest_timings.json`: 2,631 s of serial work). CLAUDE.md says to run every selftest before a commit, so 1 worker is safe but practically punishing.
- **Live right now:** no seat holds much RAM-disk memory (all under 41 MB). Your current BENCH window has already peaked at its 10 GB cap this boot.

**The real options for today:**

| | What lands | Tests | Time |

| **A. Phase 0 as written** | Refuse clones into `/tmp`, the Claude built-in tool cap at 6G, terminal reset after a crash, tests 16→1 in a seat | Safe, but 44 min per full run | ~1–2 h |
| **B. Phase 0 + test pen** | Same, but tests run in their own 12 GB pen *outside* the seat (`rm-harness.slice`), so they can never take Claude down, at about 6 workers | Safe and still roughly 5–8 min | ~half a day |
