## Four rules that every name follows

1. **Every call returns a receipt.** The receipt says which game, which build, what the call changed, which bridge tools it used, and what it could not look at. You get proof of what happened. You pay a little more output on every call.
2. **Four answers stay apart.** Measured zero, looked and found none, could not read, and failed are four different results. This is your rule of November 17, built into the library.
3. **A refusal and a fault are different.** A refusal means the call was wrong and nothing changed; the message carries the repair. A fault means the game did something else; the message says what changed.
4. **Two stamps mark a run that cannot count.** TUNED means that a live value was written. EXPLORED means that the escape hatch changed the game. A stamped run can never pass a bar. The game process holds the stamp, and so does any save written from it, so a restart or a reload cannot wash the stamp off. You get free experiments with no risk of a tuned run passing as a real one. You pay a restart and a clean map before a run can count.
