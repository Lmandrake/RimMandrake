1. **Resume cost.** The cache lives 1 hour. A warm resume (same model, under about 57 min idle) costs 0.05·C plus 2× the new part: median 70k weighted on the first request. A cold resume rewrites the whole context: median 566k for Opus and 1.20M for Fable. A model change is always cold. [measured, 39 resumes]
2. **Fresh cost.** I priced 65 continuations from the transcripts. A fresh Opus run spends a median 414k before its first new act; a warm resume spends 320k and a cold one 869k. These are not matched pairs: each continuation ran one way only, on its own task. [measured]
3. **Fresh runs have a floor.** Every fresh run here first writes 61k–129k tokens of context (both CLAUDE.md files plus the brief). It then carries 135k instead of the parent's 418k, and that smaller context is cheaper on every later request. [measured]
4. **Case A break-even.** A warm resume wins up to about 150k of context and is about even at 200k. A cold resume wins only up to about 100k, so the current rule (under 150k resumes at any idle time) loses on cold resumes of 100k–150k. Three such resumes cost 510k–897k against 414k for a fresh run. [measured; the break-even model ~70%]
5. **Case B: the Conductor's guess is half right.** The refusal record is even smaller than guessed, about 380 bytes per line. But a fresh filer costs 113k–236k (Opus) because of the floor, while a warm resume costs about 9k, so a resume is about 15× cheaper within the hour. Fresh is still the right choice, because a resumed filer can anchor on its first refusal. No LLM filer exists today: `filing_gate.py` is a program that spends no tokens. [measured / guess ~70%]
6. **Recommended rule.** Judge-like roles always start fresh. Otherwise resume when the model is the same and either the session is idle under 50 min with C ≤ 150k, or C ≤ 100k at any idle time. Start fresh in every other case. The rule also names the record the first run must leave.
7. **Untested option.** Pinging a sleeping session every 50 min to keep its cache alive may beat a cold rewrite for sleeps up to about 30 hours; no experiment has checked it yet.
