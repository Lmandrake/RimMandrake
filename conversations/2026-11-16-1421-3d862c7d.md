## Proposed definition

**A bar is a promise about what the mod adds to the game, stated as something a player would notice and miss if it were gone.**

**What a bar is**
1. **A capability, not a detail.** Each bar names one defining thing the mod lets happen, puts in the world, or changes about play. The set of bars answers "what is this mod?", not "what is in this mod?".
2. **Few.** If a mod has more than about a dozen, some are details pretending to be capabilities. This is a guide for the Designer, not a cap the Judge enforces.
3. **Checkable by an observation.** A bar must be something you could watch happen, or fail to happen, in a scene. If nobody can say what they would see, it is a wish, not a bar.

**What a bar is not**
4. **Not tuning.** A number belongs in a bar only where the feature fails or causes a problem without it, and then as a relationship or a range, never the tuned value. "The crop yields food" is a bar; "yields 12" is not.
5. **Not art or UI design.** A bar may require that a thing is visible, readable and distinguishable. It may not require which sprite, how many variants, or where a button sits.
6. **Not the base game.** Saving and loading, running responsively, settings that work, surviving a reload: these are owed by every mod and are checked once, by a shared floor that all mods pass. They are never restated per mod.
7. **Not absolute load.** A bar may limit the mod's cost relative to the same scene without the mod. It may not name an absolute frame rate or time, because the rest of the mod list is unknown.
8. **Not complete coverage.** Bars cover the key capabilities. Everything else is covered by ordinary tests, which can change freely without re-passing anything.

**The three tests a Designer or Judge applies**
- **The retune test:** if we renormalized every number, redrew the art, or rearranged the UI, would this bar need re-passing? If yes, it is not a bar.
- **The removal test:** if this were deleted from the mod, would a player say the mod lost something it is for? If no, it is not a bar.
- **The any-mod test:** could this sentence be said of any mod at all? If yes, it belongs to the shared floor.

**What a Judge may refuse for**
- A promised capability has no scene that would show it failing. That is a real gap.
- A bar is not observable. That is a real gap.
