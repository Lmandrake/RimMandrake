**1. Download the BIOS**
- Go to ASUS support for the **ROG STRIX Z890-E GAMING WIFI**: Driver & Tools → BIOS & Firmware.
- Download the newest **non-beta** BIOS and read its release notes.
- A web search didn't confirm which version is newest. The ROG forum mentions 2006 and 2201, and one user reports fan and heat complaints with 2201. Take whatever the official page lists as the latest stable release.
- Unzip it. You'll get a `.CAP` file and usually a `BIOSRenamer.exe`.

**2. Prepare a USB stick**
- Format any USB stick as **FAT32**.
- Copy the `.CAP` file to the root of the stick.

**3. Before rebooting**
- Close RimWorld and let the agents finish. I can hand off the BENCH and FOUNDRY sessions first if you like.
- In the BIOS, note your current settings: XMP on (the RAM runs at 6000), and any fan curves or boot order you changed. Flashing resets them all to defaults.

**4. Flash with EZ Flash 3**
1. Reboot and tap **Del** to enter the BIOS.
2. Press **F7** for Advanced Mode, then go to **Tool → ASUS EZ Flash 3 Utility**.
3. Choose **via Storage Devices**, pick the USB stick, select the `.CAP` file and confirm.
4. Wait for it to finish, about 2–5 minutes. **Don't power off.** It reboots by itself, sometimes more than once. A black screen for a while is normal while the memory is retrained.

**5. After the flash**
- Enter the BIOS again and press **F5** to load optimized defaults.
- **Leave XMP off for now.** The RAM then runs at standard speed. If the freezes stop, that separates "old BIOS" from "RAM overclock". After a week or two without a freeze, turn XMP back on.
- Restore your boot order and fan settings, then save and exit with **F10**.

**If the flash fails:** this board has **BIOS FlashBack**. Run `BIOSRenamer.exe` to rename the file (to something like `SZ890E.CAP`) and put it on the stick. Plug the stick into the rear USB port labelled FlashBack and hold the FlashBack button for 3 seconds with the PC off but still plugged in. The light blinks until it's done.
