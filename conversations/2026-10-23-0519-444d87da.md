| | Liquid tank (short) | Tall liquid tank | Universal cargo tank | Extra-tall cargo tank |
|---|---|---|---|---|
| Moving it | Fixed where it's built | Fixed where it's built | Can be uninstalled, carried and set down again with its liquid still inside | Same as cargo |
| Size of store | The base size | Twice the short tank, same 2×2 footprint | "A large quantity" | Twice the cargo tank, 64,000 L |
| Cost | 150 steel, 3 components | 285 steel, 5 components | 220 steel, 4 components | 400 steel, 7 components |
| Liquid | One at a time | One at a time | One at a time, any liquid at all | Same as cargo |

All four are 2×2 and join pipes the same way.
