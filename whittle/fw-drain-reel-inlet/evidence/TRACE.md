# Traced production paths and scope

- HosePorts.RawFind: parent Map, r.Rect from actual OccupiedRect, cardinal perimeter outside cells; Classify, stable id sort, HosePortRule.Pick. No depth gate originally. New pair is perimeter pc and inward-clamped cell; because perimeter excludes corners this is exactly contact - side. Filter both candidate collection and Pick's contact selection; all-contact failure permits another candidate. HashSet scratch is retained between calls.
- HoseMath.HoseReelRect.PerimeterInto / EdgeCells: side order E,N,W,S, ascending z on E/W and x on N/S. Pick rejects None/overlap, ranks kind/side/edge-index, keeps first id on exact ties. Optional set constrains contact before ranking. Other callers omit it and retain old behavior.
- RM_HoseBands.BandAt: rules-off/map-null/out-of-bounds/no excavation engine =>0. Otherwise HoseBandMath.Band over real RM_SuperdeepTrap.StepDepthAt, not hollow depth. StepDepthAt can read water/decks differently; the fast adapter explicitly doubles the engine boundary, while the live scene uses actual dry excavation.
- HoseBandMath.EndReaches is equal-band only. P5 design explicitly separates endpoint reach from routes down ramps/ladders. RM_HoseBands.Linked allows FloorJoined, actual RM_PitRamp.Joins or the deeper cell's real ladder with HangsToward+Reaches; LadderCarriesHose ignores raised. These route permissions do not authorize cross-band inlet endpoints.
- RM_PitRamp.Joins reads ramp at deeper cell, facing toward high cell, and RM_CliffMaskMath.RampJoins span. This is cardinal transition permission, not a port exception.
- Pump: ReelSideOn uses the reel's real OccupiedRect and pump Position marched out of actual footprint by RM_PumpPortMath.PortCell. RawFind now constrains pump candidate geometry to that side's single interior port cell; an unrelated reachable lane cannot authorize the designated port. Find retains PumpSideTakes lower-id one-port arbitration. Its competing-body RawFind now uses the same depth/contact restriction; RawFindAt is unchanged.
- CompHoseReel.Port caches Find's object, side/contact/kind for up to 60 phased ticks; forced reads refresh the cache and may bump linkInputSerial. RM_LiquidNet.cs RM_HoseLinks.Ends consumes r.Port as hydraulic inlet unless comp.IsFed supplies a relay inlet. Fixing Find cuts this body-port input. It does not change relay indexing, cached refresh cadence or hydraulic transfer algorithms.
- Draw consumers include RM_MapComponent_Hoses.DrawFeed and RM_LiquidJoins couplings. No GSS source/assets or FlowWorks art changes. Exact GSS hashes are carried in integrity manifests. Existing art approval is preserved by bytes, not a new visual certification.

Fast adapter: all non-SelfTest production files from the normal SelfTest compile list plus complete HosePorts and RM_HoseBands; explicit Verse/world/component/engine doubles in AdapterStubs.cs. No method extraction or copied algorithm. Real-style pump Position is explicit in dedicated cases; default fake Position is origin. Ladder/ramp booleans are permission witnesses only; water/decks/cover/placement and full liquid-net consumers are not simulated. New normal selftests test production Pick (including an independent edge-list test oracle) rather than pretending engine doubles are the engine.

Evidence integrity_original.json is a post-repair, pre-suite baseline despite the reused observer's filename. Original shipping HosePorts/HoseMath snapshots and isolated original-build input receipts carry original-code evidence. Entire original strace is retained externally, never removed or replaced with a filtered copy.
