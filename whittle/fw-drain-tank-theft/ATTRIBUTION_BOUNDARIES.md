Actual successful tank mutations record signed decilitres by liquid only while the synchronous initiator scope belongs to the player and the tank belongs to a foreign faction. A scope always replaces the previous actor, including an owner or null actor, and Dispose restores it. Tank validation precedes recording; removal captures the liquid before emptying the tank.

Pumps scope their actual draw/pour bodies. Converters, pipe adapters, reactors, bath/ice-melter completions, sprinklers and faucets supply the machine or bill giver. Tank bottle and thirst jobs scope the completion callback, not a suspended iterator. Hose FillFrom/Credit delegates execute synchronously inside the caller scope. Levelling moves world stock without a tank mutation. Tank settling supplies the actual Empty source or Fill destination; dump/drain supplies the actual dumping tank. An unrelated player mover elsewhere on the net supplies no actor for another transfer.

The compiled GlowTank reflection bridge supplies the actual GlowTank through the same public actor API, with IDisposable spanning discovery, success, refusal and exception handling. A loaded legacy FlowWorks API without actor scopes turns this optional feed off through its existing shape warning; absent FlowWorks stays a silent no-op. Cauldron's compiled gas-tap Deliver body supplies the actual parent. Its whole-bank acceptance and bank debit stay unchanged.

Rollback legs run inside the same scope. Equal opposite player changes in the same liquid cancel; partial restoration leaves only the actual residual change. Different liquids have separate entries. Owner replenishment does not erase a player's withdrawal. The next theft pass consumes pending changes even when theft is disabled, the owner changed, the faction is defeated or no witness exists; such changes cannot be charged later after a toggle. The pending victim and per-liquid journal persist through tank ExposeData. Historical caught/remainder state and the existing witness/goodwill policy remain separate.

Unscoped setup/debug mutations do not attribute theft. Explicit setup exemptions are FlowWorks ruin stocking, Cauldron non-player ruin stocking, and named existing tank/hose proof setup. Unknown third-party mods that bypass the actor API are outside this trace. There is no net-global fallback or opportunity-based charge. Current repository callers were searched across src and the known external bodies are executed in the normal FlowWorks test entry point. Live proof covers actual pumps, hose topology, real witness and goodwill plus on-disk pending save/load; optional GlowTank and Cauldron integration bodies have offline production-extraction coverage.
