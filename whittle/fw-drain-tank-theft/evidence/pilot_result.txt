## Weak checks

1. **The timing check:** it leaves out a tick the script itself causes, so it can never pass as written (this is run 3's failure).
2. **The round-trip comparison** (`tank_theft_live.py:240`):
   - It checks only 8 fields and skips `caught`, `charges`, `goodwill`, `victimGoodwill` and `reach`.
   - It doesn't check the source water level either.
3. **The recorded timing note** (`:263`) says "two pump-disabled setup ticks", which is false: one of the three ticks was a load tick with the pump on.
4. **Limits to record:** these must be written into the proof's evidence, not left implied.
   - `prime` artificially fast-forwards the rest of the caught day.
   - `theft('tick')` skips the normal scheduling.
   - Pump power is forced on with a dev tool.
   - The power re-apply branch at :249–254 never ran in run 3.
