- A1 found that a correct sine-squared formula can still draw kinked pole joins if the end samples disappear. PipePoleChecks now scopes SpanCurve, Droop and SpanTs, pins the 0.08/0.16/0.3 end samples and their symmetric quarter-span additions, and rejects mutations that remove sample selection, the sample values or the end-addition condition. Formula, length scaling, endpoint and old-parabola mutations also run in memory. The local math sweep checks symmetry, bounds and the flat end slope. Actual GSS angle and rendered-pixel tests are outside this FlowWorks run.
- A2 found that Pin strings anywhere in the capture driver could conceal calls moved into Repath. RelativeRulesChecks now scopes reach and hold separately, requires each pin inside its Hold branch and one pin call per section, and rejects moved/deleted calls. It also checks the helper's requested job start/expiry, the already-pinned early return, stopping movement, Never completion and release when the warden stops capture. In-memory deletions exercise those lifetime checks. Engine expiry/resume behavior requires runtime evidence beyond this task.
- S1 prompted a thirst gate-order check. The local Consider affordability refusal must precede reachability counting. A mutation moves the gate behind reachability and is rejected, alongside missing refusal, false continuation, reversed callback and early admission mutants.
- S2 prompted per-method draw-call counts. A planted unconditional second white-water draw is rejected even when the gated draw remains present.
- S3 prompted a wording audit. The original pond case counts THREE unit-times-beds assignment occurrences. This evidence makes no claim that it identifies every method or every capacity assignment.
- S4 prompted inspection of HoseCorridorVersions and ReplayTick.CorridorMoved. The existing whole-map dirty-list and bounded-patch tests cover snapshot convergence in this run. Corridor-version math is compiled by the separate replay project and has a skipped-hash oracle there. This task adds no replay or test-project scope. Direct corridor-version execution is unclaimed.
