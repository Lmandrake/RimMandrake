Readback of the current production contract (shipping source unchanged).

DrawAll is visited in rotating reel order, not rank order. With LegacyFrame false, its carried-with-trail and null-lay branches call DropMeshes before continuing; Retracting drops before consulting the cache, then clips with key=null and cannot recreate a persistent laid mesh. An empty carried trail falls through EnsureLay: production EnsureLay returns null for an unlaid reel. DrawCarrying creates carryCache/frame meshes, not the laid mesh dictionary or crossing index. Register/Deregister and ApplyLay also drop laid caches; MapRemoved clears the index.

DropMeshes destroys the old laid flat/plump/ground/over/cross meshes, removes the dictionary entry, drops the strand from HoseCrossShadows, and destroys/removes any stub cache. HoseCrossShadows.Drop removes its own id and marks nearby surviving strands dirty. Check recomputes a pending strand's lower set using current ranks and per-build serials; a changed key recalculates spans. DrawCrossShadow passes these spans to the production BuildCrossMesh, which destroys its prior mesh, clears it and recreates one only if nonempty spans produce triangles. A surviving active laid lower still contributes the same all-pairs geometry.

LegacyFrame starts false in shipping production. FrameLegacy is a deliberately retained opt-in comparison hook. Its carry/null/retract branches retain old laid caches and its all-pairs shadow path reads those caches. This is the expected historical comparison, not the shipping default. Ordinary DropMeshes still removes from the index while LegacyFrame is selected, and a later default draw catches carried/unlaid/retracting entries. New cache builds and RanksMoved maintain the index during the comparison mode.

Limits are part of this bounded verification. If an upper is visited before a newly inactive lower, its already-drawn mesh may include that lower for one frame; the later drop leaves it pending. If crossing work is over budget, an affected upper keeps its old mesh and pending dirt until a later scan. The existing draw rotation/fairness and HX5 queue tests cover recovery mechanisms; no universal wall-clock or maximum-frame bound is asserted. During retraction the whole old laid strand leaves the index, so even the still-visible clipped portion receives no crossing shadow from above. When drawing is skipped (world map/settings), cache maintenance catches up on resumption with the same order/budget limits.

Coverage boundary: the new test target compiles seven complete production method bodies unchanged: DrawAll, DropMeshes, DestroyMeshes, DestroyOver, DrawCrossShadow, RebuildCrossShadow and BuildCrossMesh. It directly compiles the real HoseCrossShadows/geometry/carry-clipping/key-memo/draw-rotation classes. It does not compile the whole Verse-bound RM_MapComponent_Hoses class. Engine lay discovery, material/mesh calls, clock/settings, ranks and unrelated fittings/mates are explicit doubles. RibbonInto records triangle submission; rendered pixels, actual game transitions, Verse scheduling, full-list behavior and Unity deferred destruction are not verified. The existing HoseCarryChecks source guards and HoseCrossShadowChecks all-pairs/fuzz/budget/rank tests remain intact.
