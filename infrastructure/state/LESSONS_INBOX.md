Verified live: identical mod combo that crashed 100% before the fix now loads clean (0 config/crossref/patch/typeload errors, 3 colonists spawned, map playable) after rebuild+redeploy+restart. General lesson: any abstract engine-extension base class meant for "auto-discovered by reflection, only concrete subclasses do anything" (Alert, and likely anything else using `AllLeafSubclasses` rather than `AllSubclassesNonAbstract`) needs its own inert concrete leaf shipped alongside it, or it is a landmine that only detonates in mod combinations lacking a consumer.
