- RimWorld's load-abort string is 'Caught exception while loading play data', NOT only 'Recovered from incompatible or corrupted mods' — a watcher grepping just the latter reports a dead load as still-loading (2026-09-08).
- A raw `--` inside an XML `<!-- -->` comment is illegal XML (spec-forbidden), and RimWorld's parser rejects the whole file — silently to us, but the game auto-opens an error-log popup on each such file. Our house style of using `--` as an em-dash in prose comments ("fails silently -- nothing logs it") produced exactly this on Armoury/About.xml (ARMOURY_LOADAFTER_STALE_1, 2026-09-08), wedging the owner's live game behind ~8 stuck popups until BENCH found and fixed it. Any subagent writing a long prose comment into an XML file must be told not to use `--` inside `<!-- -->`, and the writer should xml.etree.ElementTree.parse() the file afterward — ElementTree correctly rejects this, it is not a lenient parser here.
