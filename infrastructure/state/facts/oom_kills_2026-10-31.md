## Per-arm caps

Every arm shared one slice. Nothing in `src/RimMandrake/Utils/arena/` sets a `MemoryMax`, and one
`rm-arena-replay.service` now runs every arm. So one arm's blowup squeezes every other arm, and every test, in
`rm-harness.slice`. The trial design already asks for one capped child slice per arm. That work is
`ARENA_ARMCAPS_ENFORCE_NO_SHARED_TROUGH`. It is owed before any relaunch and is not this item's, because the arena tree
belongs to another owner.

## Instrument fix made here

`oom_attribution.py --since` read its kernel half with `journalctl -k`, which implies the current boot, so this window
read **0 kills; 17 were there**. It now reads `_TRANSPORT=kernel`, takes `--until` and `--boot`, and names the child
unit of the limit that fired (`in rm-harness.slice  unit rm-arena-replay-v3.service`). Lesson
`infrastructure/state/facts/instrument_traps.md`.
