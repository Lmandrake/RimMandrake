# RIMMANDRAKE_DECIDE_GUARDS_OWED_BY_LANDED_OLD_FIXES

## spec

The 2026-11-18 old-era sweep (`design/RimMandrake/old_era_ticket_sweep_2026-11-18.md`, class DONE, GUARD OWED) found
69 pre-Maturation tickets whose work landed on origin and whose own selftests exit 0 on HEAD, but which `rimflow close`
refuses: each was closed once, its live promise broke since (deadman `live --result broken`), and a fix that died closes
only with a class guard test shown failing on the instance (`model.guard_owed`). Most of those deaths were not the fix
failing [measured: the deadman events]: aggregate ops alarms (STEVE_INCIDENT_UNCLAIMED, QUEUE_STALLED designer,
GAME_HEALTH, UNTRIAGED) read as a relapse of every fix in their family, the 2026-11-07 timer stop (rm-metronome.timer
disabled), and 2026-11-08 hook-wiring reads from a clone without hooks.

The Conductor decides, for the list below: write a class guard per item, or lift the guard by its authority
(`--per-ruling CONDUCTOR_AUTHORITY_DECIDE_NO_ASKING_MOM`) where the death was not the fix. The sweep did not lift them:
lifting a guard is the owner's word on a close, not a sweep's call.

## verify

Acceptance test: none, a decision. Done when each item below is closed or has its own guard ticket.

## criteria

- L0: no item below is open without a decision note.
