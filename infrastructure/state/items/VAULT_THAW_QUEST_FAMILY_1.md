## spec
Full design + build record: `design/Jawa/worldbuilding/vault_thaw_quest_family.md`.

The six vault layouts (`VAULT_DUNGEON_BUILD_1`) had no QuestScriptDef family:
nothing offered, gated or resolved a visit; the reversal, the sleepers, the
ship-claim and the Reclamation hung off nothing. This item builds that family
in `src/RimUtinni/VaultDungeons/` — eight `QuestScriptDef`s generated by
`Source/gen_vault_quests.py`:

- `RUT_VaultThaw_V1..V5` — natural pool behind `RUT_Antiq_Cartography`
  (Antiquities: CARTOGRAPHY reveals vault sites), a Site generated on the
  RULED fixed tile, content through `SitePartDef` → `GenStepDef` →
  `KCSG.GenStep_CustomStructureGen` on the existing template, 325×325.
- `RUT_VaultThaw_V6_Umbra` — also behind `RUT_Antiq_Voice`; the thaw is the
  Assailant complex's frozen-first-impact model in vanilla comps
  (`RUT_VaultHeart`: a dead power plant fed one `AIPersonaCore`, one-way);
  wake / loot / leave as three signal branches with the ruled verbatim line.
- `RUT_VaultClaimConflict` — demand, refusal (a walk-in raid of the woken),
  departure with a grudge; chained from a wake.
- `RUT_Reclamation` — the ruled late-game event: Helix flip to hostile, two
  waves, the two ruled scenes after; chained from the refusal.

## Watch out
✅ **Built 2026-09-12, FOUNDRY: the C# sender for V6's WAKE/LOOT branches.**
`MapComponent_VaultSleepers` (auto-instantiated per map like its
`GameComponent_WarLabCrater` sibling, no Harmony) watches the vault's own
`AncientCryptosleepCasket` things and fires `QuestUtility.
SendQuestTargetSignals(map.Parent.questTags, "RUT_SleepersWoken" /
"RUT_SleepersLooted")` the instant one transitions:
- **ejected while it survives** (`!HasAnyContents && !Destroyed`) — reached
  either by a colonist's "Open" job (`Building_Casket : IOpenable`, right-click
  Open or the Open designation both reach here even on a hostile-faction
  casket — `CanOpen` has no faction check) or by combat damage
  (`Building_AncientCryptosleepCasket.PreApplyDamage` calling `EjectContents`
  directly). Vanilla's own `EjectContents` then spins up the
  `LordJob_AssaultColony` for the Rakata soldiers — this IS the wake. → WAKE.
- **destroyed before ever ejecting** (`Destroyed` while still tracked as
  unopened) — the sleepers went down with the casket. → LOOT.
- Gated to only run on a map whose `Site` carries `RUT_VaultSite_Type3` and
  has quest tags; every other map's copy of the component no-ops on its first
  eligibility check and never polls again.
- `contentsKnown` (the field that would make this trivial) is `protected` on
  `Building_Casket`, unreachable without a patch — `HasAnyContents` +
  `Destroyed` give the same two states from public API, so no Harmony patch
  was needed after all; the design doc's own proposed shape ("a MapComponent
  or Harmony postfix") turned out not to need the postfix.
- Compiled clean (`RimMandrake.Utinni.StructureInjectionsRUT.csproj`, one new
  `<Compile>` line); **not deployed to the live Mods folder** and **not
  quicktested live** this pass — see `verify`. The WAKE/LOOT letters, history
  events and the chain into `RUT_VaultClaimConflict` remain unproven in a
  running game; that is this item's one honest gap, not a fabricated pass.
- `Site.AllEnemiesDefeated` being spent at arrival (type ①/③ threat-free on
  landing) is unaffected by this build and was never in scope here — ① uses a
  live garrison so `AllEnemiesDefeated` fires normally there; only V6's
  frozen-on-arrival state needed a different signal, which is what this
  sender supplies.

⚠️ **Deliberate divergence from §3.9's six `world_commit` placements:** vault
content now arrives as a quest Site at the fixed tile, so the bridge writes
are needed only for V5's landmark and hand-finish, not for the vaults to
exist. Say so at the next sitting before anyone spends a bridge session on
them.

⚠️ `RUT_Symbol_RakataSleeper` (the sibling's pawn symbol) named a
BackstoryDef as a pawnKindDef and would have spawned nothing; replaced by a
real casket symbol. `Mech_Centurion` cells removed from type ③ (a live
hostile on arrival would break the thaw state).
