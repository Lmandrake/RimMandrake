# STILLSAND_GEOPHONE_1 — the biosilica geophone

From `STILLSAND_GLASS_LENS_CHAIN_1` §8, which that pass did not build.

## spec

A biosilica resonator staked in the sand. It turns rumbles within its radius into coarse markers
of direction and size. It reads the sand-swim kit's submerged query (`RM_CompSandSwim`,
CreatureBehaviors). It cannot tell a drazzik's lie from a real drum.

- Art: artpipe job `RM_Geophone` is registered.
- A Mod Settings toggle.

## criteria
- A submerged swimmer inside the radius shows a marker with a rough bearing and a size class.
