# DESERT_TRIBES_FIRE_HARVEST_1 — deep-desert tribes light the Pyrelands for harvest

## spec
Owner, 2026-09-17, verbatim, ruling the FireEcology shim dead: *"The shim
remains there if we want the deep desert tribes to occasionally show up and try
to light the fires for harvesting. But that could be put into the scenario
definition as an event couldn't it? Yes that's better."*

Design the event that carries the idea forward, campaign-side:
- A deep-desert tribe party arrives on a Pyrelands map, sets fires deliberately
  (triggering the biome's own burn cycle — EmberGrass regrow, scorch-fruit
  flush, ash ladder), harvests the flush, and leaves.
- Mechanism candidates: IncidentDef fired by the scenario (Scenario_Utinni
  scenario-part), or a quest-flavored incident; the biome mod stays generic —
  this is RimUtinni-tier content.
- Fires set by the event are real fires: the player can fight them, exploit
  the regrow, or follow the harvesters.
