# MIASMA_SHIPPING_NAMES_1 — owner card: the_miasma working names

## what

Three working names shipped this pass (`COMMISSION_LEDGER_CLEANUP_1`,
the_miasma sheet), all taken straight from
`design/Jawa/worldbuilding/biomes/miasma_fauna_roster_2026-09-23.md`'s own
naming register rather than invented fresh:

- **`RUT_Karrobel`** ("karrobel") — roster §2 row 2, the delta-loam
  composter: "deep wedge body, front end armoured into a blade."
- **`RUT_Karrathil`** ("karrathil") — roster §3 row 5, the fever-swarm:
  "a loose airborne cloud with no single body to fix on."
- **`RUT_StrandedDeformation`** — a HediffDef name coined this pass (the
  roster names no defName for "the deformation," only describes it in
  prose, §5).

Note the roster's own document prospectively names the first two `RM_`
(anticipating the eventual franchise-free retiering discussed in that same
document's §4/§8), but both ship here as `RUT_` because `RUT_Miasma.xml`
has not migrated to a standalone mod yet — matching the `RUT_MortuaryCrawler`/
`RUT_FleetFlier` precedent from this same item's prior two waves: new
content takes the tier of the file it is wired into, not a design doc's
prospective future tier.
