Live check of three LongShade shade-extras that share one scene: a built map with the RM_LongShade biome, a colonist, a wild animal, a built shade patch. Built by LONGSHADE_TOLLOK_TICKS_1, LONGSHADE_LURE_AWNING_1, LONGSHADE_HARROK_STILT_1 (all closed `implemented --none-owed` with NOTHING run in game; source: Transient/belt_shadeextras_20261009.md). Needs the bridge. Scene prerequisite: a map whose biome is RM_LongShade (`jawa/map_info`); if the current map is another biome the checks below read UNMEASURED, not failed. Never a flyer, nothing visual-only.

## criteria
1. Tollok: a pawn that stands still 2500 ticks in WILD deep shade (grid.ShadeAt >= 0.7, no roof, no gear shade) gains HediffDef RM_TollokInfestation; the same pawn under a built roof or under an RM_LureAwning does NOT; with tollokTicksEnabled=false nothing is added.
2. Lure awning: RM_LureAwning's inspect string reads "Game sheltering nearby: N" and, with lureAwningEnabled=false, "Lure awning switched off in Mod Settings."; the cell under it reads shade via the gear grid.
3. Harrok: a wild RM_Harrok standing in the open strikes (Stab, 12-20) a resting prey of bodySize <= 1.5 lying in the strip its shadow lays (6 cells, half width 0.9), at most once per 900 ticks, and prints the message "A harrok's shadow fell across <name>, and the harrok struck." for a player pawn; with harrokEnabled=false it never strikes.

## verify
Order: (a) `jawa/map_info` -> biome must be RM_LongShade, else UNMEASURED. (b) `jawa/get_defs` defs="HediffDef/RM_TollokInfestation" (a STRING, 'DefType/DefName'; read success/foundCount/notFound, never substring the payload); same for "ThingDef/RM_LureAwning" and "ThingDef/RM_Harrok". (c) settings: `jawa/mod_settings_field` typeName=<SETTINGS in LongShade/validation.py> action=get field=tollokTicksEnabled (also lureAwningEnabled, harrokEnabled); set true for the run.
Tollok: `jawa/shadegrid_read` cells="x,z" for a wild-patch deep cell; require shade >= 0.7 and no roof. `jawa/spawn_pawn` a colonist there, stand still (no job), `rimworld/step_game_ticks` 3000, then `jawa/pawn_health` is write-only for add; READ with `jawa/pawn_get` (pawn) and look for RM_TollokInfestation in its hediffs (if pawn_get does not list hediffs, UNMEASURED, do not substitute). Control: repeat under a built roof; expect no hediff.
Lure awning: `jawa/spawn_thing` RM_LureAwning next to a wild animal; read the inspect text via `jawa/list_things` / pawn-thing inspect output; if no tool returns the inspect string, UNMEASURED.
Harrok: `jawa/spawn_pawn` kind RM_Harrok (wild, no faction) and a downed prey colonist (`jawa/pawn_force_incapacitate`) in the strip from `jawa/shadegrid_read` SunShadowDirection; step 600 ticks; expect `jawa/pawn_get` injuries with a Stab, and `jawa/drain_log` / letter_list containing "harrok struck". Control: prey outside the strip takes nothing.
UNMEASURED looks like: a call that returned success:false, notFound non-empty, a map that is not RM_LongShade, or no tool that reads hediffs/inspect text. Record the exact reason; do not close on it. Flyer rule not engaged (harrok is a ground pole).
