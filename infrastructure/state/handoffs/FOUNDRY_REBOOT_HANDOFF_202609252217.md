GeneticRim's own bug. `RimMandrake.CreatureBehaviors.dll` had never picked up today's rebuild;
6+ of its XML-registered classes were "Could not find type named" on every load, and one of the
defs that broke left some `PawnKindDef.race` null — which GeneticRim.Core's `cctor` dereferences
unconditionally (`item.race.tradeTags`, no null check), crashing it and poisoning every later
call into it (Need Food on real colonists, all `jawa/spawn_pawn`). Before blaming a third-party
mod for a fresh-restart crash, check `deploy_custom_mods.py --mod <every mod you touched today>`
for drift first — a full-sweep `--apply` is not proof every mod actually deployed (see traps).
