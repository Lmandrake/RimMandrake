A no-loss check on a rule-file rewrite that looks for each code span, id, number and quote in ANY file afterwards passed two real losses on 2026-11-21: (1) a helper replaced a paragraph by a pointer and so removed an id that selftest_conductor_authority.py requires in EACH role file; (2) fourteen files rewritten into plain English held 6 changed meanings (a pass condition turned into a chore; 'a round, zero or alarming count' turned into 'each count'; 'never a stash or a reset' gone behind a pointer whose home does not say it). So before a rule-file rewrite is called done: run every test that reads the files, and have a second reader compare old and new text hunk by hunk. The span check alone is not evidence that the meaning stayed.
