Wrap-up debts are in-process game state (DebugSettings, loaded game's difficulty, ModSettings statics that jawa/mod_settings_field never writes to disk, scenes on disposable maps): a debt owed before the game's last launch is void. wrapup.void_debt reads Player-prev.log mtime (Unity rotates at launch, keeps mtime). Before this, every relapse of the wrap-up alarm was such void debts resolved by hand (RELAPSE_WRAPUP_FIX_DIED_TWICE).
