deploy_custom_mods.tree()/compare() cache each root's inventory for the life of the PROCESS until forget()/forget_all(). An importer that walks the same root twice (modcheck run_identity START vs END deploy fingerprint) silently reuses the first walk: a file added or deleted between the two is invisible, so a mid-run redeploy could prove 'fresh'. Call forget_all() before every walk that must see NOW (fixed 93561110e0/8929d6cf60). The selftest's own hold control had been red on HEAD because of it -- a red control is a bug report, run it before trusting a CLEAN mark. Also: passing an ABSOLUTE path as a git pathspec through wsl.exe git from Windows python yields a \\wsl.localhost string that matches nothing (rc 0, empty) -- a dirty tree reads clean; always pass repo-relative pathspecs.
