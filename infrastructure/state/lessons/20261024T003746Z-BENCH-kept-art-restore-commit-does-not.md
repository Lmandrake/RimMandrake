art_guard check_range checks every unpushed commit on its own (rev-list base..head, per-commit diff-tree), not the net diff: a commit that replaced owner-kept texture bytes without an authorized live event stays refused even if a later commit restores the kept bytes. Only fixes: an authorized live event (owner ruling, or the pipeline-regen by-card exception), or rewriting the unpushed commit. Also: machine-template art (incl. module part) without scale+assembled panels is HOLD_INPUT, so the kept-art redraw exception can never fire for it without an in-game capture.
