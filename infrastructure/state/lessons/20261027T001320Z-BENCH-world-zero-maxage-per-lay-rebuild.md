A snapshot accessor called with maxAge 0 on a hot path rebuilds the whole artifact every tick even when its version proves nothing changed: hose TakeLayWorld called World() (maxAge 0) per started lay, so round 8 T2 did ~100 whole-map CordWorld rebuilds (+ clone pool drops, ~0.85 MB each on a 325 map) in a 300-tick relay wave and forced full GCs. When a snapshot is versioned by change events, readers should pass the largest age their correctness allows (World(60)), and the census should count rebuilds (worldBuilds) so the rate is visible.
