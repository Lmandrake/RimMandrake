A fuelled crafting station with CompHeatPusherPowered heats whenever it holds fuel, and consumeFuelOnlyWhenUsed keeps it fuelled, so it heats 24/7. To heat only while worked use thingClass Building_WorkTable_HeatPush with building/heatPerTickWhileWorking (vanilla FueledStove 0.10); it pushes from UsedThisTick. Tar vat fixed c8fc7fac4e.
