Leaving RimWorld's World-tab UI open is NOT tied to which map is `Current.Game.CurrentMap` — `jump_camera_to_cell`'s response can report the right `mapId` while the visible screen still shows the World/Terrain overlay, and `CameraJumper.TryHideWorld()` (inside `jawa/set_current_map`) does not reliably stick across later calls. A screenshot is the only way to confirm which screen the owner is actually looking at; don't infer it from a tool's `success: true` (FOUNDRY 2026-09-25, SCALD_WATER_AGITATION_FLECKS_1).
