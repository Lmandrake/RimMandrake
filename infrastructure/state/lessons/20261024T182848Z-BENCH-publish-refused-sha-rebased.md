When ./publish prints REFUSED (a foreign dirty file blocks reset --keep), the commit stays local and a later publish by another seat rebases it to a NEW sha. Closing the item with git rev-parse HEAD at that moment records a sha that never reaches main (batch A 2026-10-24: closed at 65097834dd, landed as cd408bbf12; fixed with rimflow note). Close only with the sha a PUBLISHED line prints; if refused, hold the close until it publishes. Separately: winbuild compiles the working tree, so in a shared clone another seat's dirty .cs is baked into the DLL you commit (srchash shows it); build from git archive HEAD + your files when anyone else has dirty source.
