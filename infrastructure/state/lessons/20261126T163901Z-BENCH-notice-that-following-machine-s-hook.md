A notice that a following machine's hook reads is not an order to its runs. On 2026-11-26 the run on SteveDesktop heard only the checkpoint text 'Carry on and finish your work', once. Only a control-store stop order (order_runs or pipe stop), written on that machine's own store, tells a run there to save and end. Before you claim that a run 'gets the save order', read the hook's words in the run's transcript (the PostToolUse hook_additional_context lines).
