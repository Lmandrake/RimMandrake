arena_judge.py hides the arm map from judge-side Linux processes with bwrap (tmpfs over the private dir and the arm clone root), proven by selftest. The GPT judge, via gpt_consult.py, runs codex.exe as a WINDOWS process with --sandbox read-only, which the Linux mount namespace does not confine: it could in principle read the map through \\wsl.localhost. It receives only the inlined prompt and names no path, but this residual is open; the arm-guess binomial report is the detector. A fix would need gpt_consult to run codex with no file access, or the map stored encrypted with a key outside Windows reach.
