After rimflow close moves an item's prose to items/closed/, do not 'git add' the old path yourself before ./publish: once its deletion is staged, ./publish's own 'git add --all -- <old path>' fails ('pathspec ... did not match any files', REFUSED rc 2, 2026-11-19). Name the folder instead (./publish ... infrastructure/state/items) when only your moves are dirty there, or leave the old path unstaged so publish stages the deletion.
