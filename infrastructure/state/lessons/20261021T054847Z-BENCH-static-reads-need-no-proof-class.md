A live proof needs no new C# to read a mod's public static counters or settings: jawa/mod_settings_field action=get/set resolves ANY public static field by type FullName (it tries STATIC first), and jawa/static_call takes typed args ('|'-separated: Map as 'current', IntVec3 as 'x,z', Pawn by bare thingIDNumber) for any public static method. Before listing a reader as owed C#, check whether the mod already exposes the value as a public static field or a static method with coercible parameters (drawbridge 6b: RM_Drawbridges.TippedCount/FellCount/CrashCount/RepathCount and RaisedAt/FreeHostileCount/Locked, RM_SuperdeepTrap.IsTrapped were all reachable; only staging and per-leaf state needed a proof class).
