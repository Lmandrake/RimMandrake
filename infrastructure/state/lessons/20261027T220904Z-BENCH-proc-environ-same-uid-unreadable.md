A /proc/<pid>/environ scan for a marker env var is never clean on this WSL box when it requires reading every same-uid process: this user's systemd (user manager), (sd-pam) and ssh-agent are same-uid but non-dumpable, so open(environ) raises PermissionError (measured 2026-10-27, bench). Treating 'unreadable' as 'not ours' hides a run; treating every unreadable one as blind blocks forever. Rule that works: rule a process out only on positive evidence (exited, other uid, or start time from /proc/<pid>/stat field 22 + btime older than the run's start minus 5 s, since the marker is inherited); anything else unreadable = UNMEASURED. Also: systemd 259 user scopes honour RuntimeMaxSec (TERM at the bound, KILL TimeoutStopSec later; a TERM-ignoring child bounded at 5 s died at 35.4 s via claude_bounded.sh with Result=timeout).
