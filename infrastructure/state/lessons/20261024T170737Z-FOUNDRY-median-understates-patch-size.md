Sizing organic patches (glass panes, blobs) in hex cells: the median patch area understates what the eye reads, because the big patches carry most of the visible colour. Round-3 Twilight panes measured median 4.5 hexes but area-weighted median 7.5 (half the lit glass sits in panes >= 7.5), and at mid zoom the eye-catching panes read 8-10. Report both (pane_metrics in src/RimMandrake/Utils/art/world_water_variants.py) and, when the owner gives a size target, show one row hitting it by each measure. Also: one hex = 0.866 x (centre-to-centre width)^2, not width^2 - forgetting it understated r2 panes by 13%.
