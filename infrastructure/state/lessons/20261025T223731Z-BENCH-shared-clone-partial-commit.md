In a seat clone shared by parallel helpers, when one file holds both your hunks and a peer's: the house hook forbids a pathspec-less git commit, and a pathspec commit takes WORKTREE content (sweeping the peer's hunks in). Working route: stage filtered hunks (git diff -U1 > p; drop hunks; git apply --cached --recount), then build the commit in a PRIVATE index (GIT_INDEX_FILE=scratch/idx; git read-tree HEAD; git apply --cached mine.patch; git write-tree; git commit-tree -p HEAD; git update-ref refs/heads/main NEW OLD). Two more walls follow: code_review_status mark-clean refuses such a file until the peer commits, and ./publish refuses (DLL_SOURCE_STAMP_GUARD_1) while any peer's build left the mod DLL dirty, so the commit sits local.
