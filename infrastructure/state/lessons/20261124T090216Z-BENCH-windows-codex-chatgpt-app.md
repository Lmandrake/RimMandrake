The Windows Codex on Archmagi is the ChatGPT desktop app (Store package OpenAI.Codex, startup task enabled, service CodexSandboxService.OpenAI.Codex). Moving C:\Users\Mandrake\.codex or AppData\Local\OpenAI\Codex makes the app's next start (login) set up a new folder, which raises the consent dialog. Only the .codex_* worker folders may move (windows_codex_archive.py).
