A raider (or any pawn) holding the same job for 10,000+ ticks with no progress is not necessarily stuck: read the work toil's duration first. RM_RaiderFillTrench's Delay toil is sized by the deep-dig cost curve x MiningSpeed, so one notch at D8 took ~22,400 ticks for a gunner (MiningSpeed 0.336) -- 'stall' was a cost bug, not a think-tree bug. jawa/static_call takes multi-arg as 'a|b|c' (comma fails) and cannot pass byte args.
