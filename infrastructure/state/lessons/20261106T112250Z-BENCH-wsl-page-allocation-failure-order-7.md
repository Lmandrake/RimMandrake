WSL 'page allocation failure: order:7' (vmbus_alloc_ring <- hvs_probe, every new hv_sock channel: /mnt drvfs and interop) is watermark starvation, not fragmentation alone: page cache holds MemFree at the low watermark, so compact_memory finds nothing to build from and drop_caches is refilled in minutes. Fix: min_free_kbytes=1GiB + watermark_scale_factor=200 (src/RimMandrake/Utils/systemd/90-rm-order7.conf, /etc/sysctl.d, rm-order7.timer). Root without sudo: wsl.exe -u root.
