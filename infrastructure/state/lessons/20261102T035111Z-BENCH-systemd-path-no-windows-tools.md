Anything the relentless supervisor (systemd user unit rm-relentless.service, PATH=~/.local/bin:/usr/local/bin:/usr/bin:/bin) starts has no /mnt/c Windows dirs on PATH: powershell.exe and python.exe are OSError there, so a game probe silently reads 'no running game' and a bridge call cannot run. Measured 2026-11-01: the first automatic live round (RA_S09) said 'no running game' while RimWorldWin64 ran. Fixed for the live round by relentless.windows_path() in live_round_launch (189568fd46); any other Windows call the tick makes needs the same env.
