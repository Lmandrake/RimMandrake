arena_spend (schema arena_task_spend/2, fe4436d196) attributes per-(arm,task) spend BY CLOCK: a call lands in the span whose [start,pass_end] holds its timestamp. Residuals that are not caught: (1) meter-clock skew vs event-log clock can move a call into a neighbouring task with no ambiguity flag (GPT r1#1); the real fix is carrying task/execution id on metered calls; (2) GPT calls with no arm tag (UNTAGGED) go to overhead, not blocking, so an arm that forgets its tag looks cheaper; (3) ralph_c running tasks concurrently makes overlapping spans ambiguous -> blocking -> UNMEASURED. Any BLOCKING_DIAG diagnostic blocks the whole run by design.
