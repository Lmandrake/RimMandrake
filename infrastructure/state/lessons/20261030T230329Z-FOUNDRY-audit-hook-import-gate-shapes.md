Python audit-hook sandboxes on 3.14: (1) frozen stdlib modules (ntpath, runpy, importlib.util) load via marshal.loads, so a hook that denies marshal kills 'import pathlib' — pre-import them before installing the hook; (2) the 'import' event fires even when sys.modules[name] is None, AND an extension loader's exec_module raises 'import' with args (name, path, None, None, None) — so 'allow if sys.modules entry is None' lets PathFinder.find_spec+exec_module load a denied module; distinguish by arg shape and raise ImportError from the hook instead; (3) _interpreters.create() raises no audit event on 3.14, so the module must never load. Probe each bypass, don't reason about it.
