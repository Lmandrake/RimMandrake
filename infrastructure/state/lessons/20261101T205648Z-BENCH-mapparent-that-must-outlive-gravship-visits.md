A MapParent that must outlive gravship visits needs CanBeSettled=false (MapGenerator hands a settleable parent to GravshipUtility.SettleTile, which destroys it on landing) and an Abandon override (a launch with no grav anchor calls Abandon, which destroys it). A proof that generates the map by GetOrGenerateMap cannot see either: only a real landing did. Landing on an EXISTING map leaves the marker unspawned until Designator_MoveGravship picks a spot, so jawa/gravship_land reports no marker; rimbridge step_game_ticks may advance fewer ticks than asked, so poll state, never a tick total.
