Before moving an SWBestiary port to the RM tier, grep for an RM_ twin of the same creature (git grep '<defName>RM_<Stem>' and the RSW_ name in src/RimMandrake headers): the 2026-09-27 Q1 tier move already made RM_Vozzik and RM_Vekka (=RSW_SandLion) in Stillsand while leaving the RSW_ originals for the frozen Utinni RUT_ExtremeDesert. A name-collision check alone reads that as a clash; it is a dedupe (retire the RSW_ copy, alias RSW_->RM_, repoint Utinni). Also check for Class="RimMandrake.StarWars.*" comps: the def cannot leave SWB until that C# lives in an RM assembly.
