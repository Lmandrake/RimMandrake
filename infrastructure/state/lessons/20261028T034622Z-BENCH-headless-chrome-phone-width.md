Headless Chrome on Windows will not make a window narrower than about 526 px, so --window-size=390,... renders a 526 px page and hides phone overflow bugs. To screenshot a 390 px phone layout, load a host.html holding a 390 px wide iframe of the page (example: D:\ClaudeWork\rimmandrake\pulse_timeline\host.html).
