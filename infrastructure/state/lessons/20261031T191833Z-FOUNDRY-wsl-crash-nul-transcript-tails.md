A WSL crash leaves Claude Code transcripts (~/.claude/projects/*.jsonl, incl. subagents/) ending in one all-NUL 'line' with no newline. spend_census counts each as a bad line, and the arena meter treated any bad_lines as blocking, so 6 such stale seat transcripts from 2026-10-06/10-21 voided a real 2026-10-31 verdict. The fix excuses only provably stale NUL tails in the harness root and reports them as flags. Lesson: a meter that scans a whole shared directory inherits every old corruption in it, so judge a bad line by WHERE and WHEN it is, not just by its presence.
