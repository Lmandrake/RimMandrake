RimWorld launched directly as RimWorldWin64.exe -savedatafolder=<dir> (Steam already running) keeps Config, ModsConfig, Saves and DefDump in <dir>, but Unity still writes Player.log to the Windows user's LocalLow. A fresh savedatafolder lacks JawaBench/companion_profile.json (companion then reports 'campaign', modcheck refuses) and Prefs.xml runInBackground True (game_focus preflight FocusRefused); rw_game.sh init seeds both. Prefs.xml is written only on a clean game exit, so seed it while the game is down.
