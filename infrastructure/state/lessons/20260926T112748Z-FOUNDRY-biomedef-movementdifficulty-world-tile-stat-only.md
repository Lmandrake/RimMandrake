`BiomeDef.movementDifficulty` is a WORLD-TILE stat only (caravan travel between planet tiles, `WorldPathGrid`) — it has zero effect on in-map walking speed, contrary to what two design docs assumed. In-map crossing difficulty is entirely `TerrainDef`/`ThingDef.pathCost` (a per-cell MAX, not additive). Verified via RimSage against `Verse/AI/PathGrid.CalculatedCostAt` (FOUNDRY 2026-09-26, `GREENTIDE_BIOME_DENSITY_1`).
