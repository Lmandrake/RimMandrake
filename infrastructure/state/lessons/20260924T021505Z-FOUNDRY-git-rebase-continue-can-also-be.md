2026-09-24 FOUNDRY: `git rebase --continue` can also be blocked by another LOCAL session (not just a remote push) advancing `main` mid-rebase directly — `update_ref failed for ref 'refs/heads/main': is at X but expected Y`. Recovery: `git rebase --abort` (safe, reflog preserves your commits), confirm the blocking commit is real with `git cat-file -t <sha>`, then `git merge-base --is-ancestor HEAD <sha> && git merge --ff-only <sha>` to restore it losslessly before retrying the pull-rebase.
