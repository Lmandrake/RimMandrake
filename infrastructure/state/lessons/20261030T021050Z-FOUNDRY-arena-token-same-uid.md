Arena event-log token cannot be secret: every seat and arm agent runs as uid 1000 (seats differ only by systemd cgroup scope), and /mnt/d drvfs shows a 0600 file as 777. Token now lives on ext4 home (~/.local/state/rimmandrake/arena_harness), refused under RM_ARM or an arm-clone cwd (defence in depth only). Tampering is made detectable by per-write signed anchors plus ledger-published ARENA_ANCHOR notes; a token-holding agent can still forge events after the newest ledger-published anchor. A real fix needs a separate OS user (or root-owned helper) for the harness.
