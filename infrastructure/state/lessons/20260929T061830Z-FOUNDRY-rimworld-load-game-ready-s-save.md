2026-09-29 FOUNDRY: `rimworld/load_game_ready`'s `save.missing_mods` refusal is RimWorld's own native mod-compat gate (surfaced structurally by the bridge, not a guard we built) — it only WARNS interactively ("some mods are missing, load anyway?") and the bridge exposes the same escape hatch as `ignoreModCompatibility: true`. A save loads to `programState: Playing` fine with it set even with several missing-mod entries. This is distinct from, and does not authorize, the separate question of whether to RESAVE the canonical save (that stays owner-reserved per CLAUDE.md's frozen-save doctrine) — the flag only unblocks read/verify-style loads, never use it to justify a resave.
