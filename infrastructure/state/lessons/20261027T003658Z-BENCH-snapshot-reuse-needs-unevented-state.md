Lengthening a cached map snapshot's lifetime (hose World(LayWorldMaxAge=60) in ab9a5392c9) turns every input the snapshot reads WITHOUT a map event into a stale-read bug: ladder SetRaised bumps only RM_LadderUtility.StateVersion (no PathCostRecalculate), so lays reused a stale ladder link for up to 60 ticks, and indefinitely while paused. Before widening a cache's age, list every input its builder reads and prove each one bumps the version; fold global counters (StateVersion, settings toggles) in at the read. Fixed 810efd679d.
