The Relentless tick no longer runs out of books: since 2026-11-06 it runs from <root>/release/current, one pinned release a day; a landed core fix waits for 04:30 or 'relentless_release.py cut --emergency --why'. A fix that seems not to have taken: run 'relentless_release.py status' before suspecting the fix. Rollback: 'relentless_release.py rollback'. Limits in relentless_rules.json, share included, arrive the same way.
