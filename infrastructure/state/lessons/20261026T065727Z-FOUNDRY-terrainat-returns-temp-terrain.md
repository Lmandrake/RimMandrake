RimWorld 1.6 TerrainGrid.TerrainAt(c) returns the TEMPORARY layer first (lava, floodwater, thin ice via tempGrid), then foundation, then top. Code that records TerrainAt to restore later and then calls SetTerrain will save the temp def as the 'original' and leave the replacement permanent once the temp layer expires. Record TopTerrainAt/UnderTerrainAt, or skip cells where TempTerrainAt(c) != null. Restore into the layer that actually holds your terrain (TopTerrainAt vs UnderTerrainAt -> SetTerrain vs SetUnderTerrain): a floor laid over your terrain moved it to underGrid. Found in RM_WalkingCondenser pool (CONDENSER_POOL_FIX_TEMP_TERRAIN_RECORDED, 8c48946233).
