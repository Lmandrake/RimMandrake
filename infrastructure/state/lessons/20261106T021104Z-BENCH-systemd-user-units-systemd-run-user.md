systemd user units and systemd-run --user one-shots start with the manager's bare PATH (no ~/.local/bin; 34 of 39 units on Archmagi set none), so a bare argv 'claude'/'claude-account'/'gh' dies FileNotFoundError under a timer and fails the unit (TIMER_FAILED 11-03, 11-05). Resolve with shutil.which(name) or os.path.expanduser('~/.local/bin/'+name); selftest_systemd_path_bins.py guards it. A machine-wide fix (~/.config/environment.d PATH) would also cover shell scripts but is not repo-tracked.
