GIT_ALTERNATE_OBJECT_DIRECTORIES pointing a sha256 repo at a sha1 repo's objects makes git log 'wrong index v2 file size in <lender>/objects/pack/...' and 'commit-graph hash version 1 does not match version 2' — it reads as a corrupt lender pack but the lender is sound. Check the borrower's rev-parse --show-object-format before blaming the pack (MIRROR_PACK_REPAIR_STILL_GRUMBLING).
