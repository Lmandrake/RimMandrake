A new `MapComponent` never activates on a map that was generated (and saved) before its DLL was deployed — `MapComponent.FinalizeInit()` only runs once, at map creation, so a save made against an older mod build carries no instance of the new component at all, no matter how many ticks are stepped afterward. Verify a new MapComponent's live behaviour on a map generated AFTER the fix is deployed, never by reloading an older save (FOUNDRY 2026-09-25, SCALD_WATER_AGITATION_FLECKS_1).
