A selftest that drives a loop end to end (ralph_a/v3/trio tester passes) writes helper captures through helper_capture.root(), which defaults to <arena root>/meter_helpers — the LIVE meter's input. Without ARENA_METER_HELPERS (and RM_ARM_SANDBOX_SCRATCH) pointed under the test's tmp dir, every selftest run planted fake tester spend into /home/mandrake/rm/arena/meter_helpers, which the next real meter would read as arm spend. Fix: every selftest that can reach capture() sets ARENA_METER_HELPERS under its tmp; check the live root is absent/unchanged after a selftest run. Also a mutation-check note: helper_capture._copy_tree's follow_symlinks=False is shadowed by the explicit S_ISLNK prune of dns, so the r2_fwalk_follows mutant is equivalent except for a swap race between the prune's lstat and fwalk's descent; it is kept as a second layer, not pinned.
