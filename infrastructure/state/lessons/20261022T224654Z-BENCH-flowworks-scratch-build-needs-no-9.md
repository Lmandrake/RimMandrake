A FlowWorks scratch build needs no 9 GB copy: 'git clone --shared --no-checkout <seat clone> <ext4 dir>; git sparse-checkout set src; git checkout HEAD' takes ~8 s (a full clone onto D:\ClaudeWork took 8.5 min plus checkout). When origin moves with another DLL commit, ./publish refuses on the binary conflict: replay the source commits onto origin/main in that scratch clone (cherry-pick, take origin's DLL), rebuild there, fetch the tip into the seat clone and 'git reset --keep' to it, then ./publish. Check first whether a peer already pushed your source with a DLL rebuilt over it (git cherry; literal-grep a new method name in origin's DLL with MEASURE_ALLOW_SCAN=1). (fixer H, 2026-10-22)
