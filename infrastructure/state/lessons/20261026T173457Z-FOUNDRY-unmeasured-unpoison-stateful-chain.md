In a stateful chain (site -> refuel -> enter -> heal) the next row then runs on an unbuilt fixture and FAILs the mod for a harness reason (Bacta: refused Refuel -> 'pawn still on map after EnterBuilding' FAIL). Keep the reset opt-in per row (independent=True) and set t.upstream_reason so the downstream UNMEASURED rows say why. 19 more validation.py files carry the copied helper (VALIDATION_UNPOISON_AUDIT_STATEFUL_CHAINS).
