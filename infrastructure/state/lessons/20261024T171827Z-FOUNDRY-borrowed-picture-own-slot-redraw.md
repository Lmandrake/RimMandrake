A creature that wears another creature's owner-kept pictures (RSW_Excretor on the feral nerf's) can be redrawn without tripping the kept-art gate by giving the regen row its OWN install_to slot (the new tier's texture path) while the spec's images still point at the borrowed art for judging. Then do NOT run fauna_drive install: it writes to the spec's images paths, i.e. over the other creature's kept pictures. Install each judged render with art.py install <mod> <own rel> --file <copy inside the clone> --by-card. After that, bulk_accept_renders lists the new slot under skipped 'live is REGEN', so the hourly installer leaves it alone.
