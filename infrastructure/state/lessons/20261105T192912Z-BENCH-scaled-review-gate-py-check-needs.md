scaled_review_gate.py check needs a sheet's img/ scale panels (~150 MB for a 119-row flora sheet) and its census, and pins never commit img/. So a blind checker on a fresh clone cannot rerun the gate: prove a pinned sheet with scaled_review_gate.verify_stamp (a body hash written only on a pass), not with 'check'. Also: a PreToolUse hook blocks any Bash command that names a Transient/biome_ffar/*_sheet_*.html path together with a write (a heredoc, a pin), so put such scripts in a file and pin in a separate call.
