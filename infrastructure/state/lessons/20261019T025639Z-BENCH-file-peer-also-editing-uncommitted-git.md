A file a peer is ALSO editing uncommitted (git diff shows hunks you did not write) cannot be committed by pathspec without sweeping their hunks: build your-only content from HEAD + your edit and commit it through a private GIT_INDEX_FILE (read-tree HEAD, update-index --cacheinfo, write-tree, commit-tree, update-ref). Staging into the shared index is not safe either: a peer's ./publish reset wiped staged blobs mid-turn and a following --amend landed on the peer's commit (2026-10-18, SUSPENSION_BASE).
