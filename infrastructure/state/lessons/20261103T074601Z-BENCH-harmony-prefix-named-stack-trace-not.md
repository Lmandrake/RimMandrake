A Harmony prefix named in a stack trace is not the thrower: Harmony lists every patch on the patched frame, so a vanilla NRE inside DefGenerator.GenerateImpliedDefs_PreResolve (RecipeDefGenerator.SetIngredients) shows VFEFactory's GenerateAutoProcesses prefix while the cause is a def with an unresolved cost. Read the innermost frame and decompile the prefix (ilspycmd) before bisecting its mod's siblings (MODCHECK_DONOR_ENVIRONMENTS_1 spent two months waiting on a needless VE bisection).
