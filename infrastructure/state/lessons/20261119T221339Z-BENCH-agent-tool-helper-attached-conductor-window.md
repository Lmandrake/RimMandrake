An Agent-tool helper attached to the Conductor window holds the window's restart and handoff until it ends; a detached run does not. On 2026-11-19 a 20-minute image-generation helper (Lodestar icon candidates) held an ordered handoff from 2:01 PM to 2:12 PM PST while the context backstop was already asking for a restart. Launch anything that generates images, waits on Codex or commits to a slow drive as a detached run, or expect the hold.
