A ThingComp's PostPostApplyDamage runs AFTER Thing.TakeDamage's DamageWorker.Apply, and Apply kills (Destroy KillFinalize) a thing whose hit points reach 0 -- so on the killing blow parent.Map is already null and any 'aboutToDie = HitPoints <= 0 || Destroyed' branch that reads parent.Map / a map component through it silently does nothing (no drop, no map-component notify). Snapshot the map in PostPreApplyDamage and use 'parent.Map ?? snapshot'. Found in Fever Wood RM_CompTentacleLimb + RM_CompTentacleEye (fix fcdedd1b3f): a 60 HP limb one-shot dropped no harvest, a porter shot dead never angered the pool, an eye killed outright never ended the pool for good.
