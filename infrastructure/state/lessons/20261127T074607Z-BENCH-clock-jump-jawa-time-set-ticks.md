A clock jump (jawa/time_set_ticks, stage_review --daylight) makes the game auto-undraft every drafted colonist on the next ticks, so a scale human or a frozen builder wanders off and can finish a half-built frame. Draft and place pawns AFTER the jump; to keep a frame half built, set Construction priority 0 for every colonist.
