On 2026-10-25 ~12:00 in the BENCH sandbox, WSL interop was off: /proc/sys/fs/binfmt_misc has only register+status (no WSLInterop), so every .exe (codex.exe via gpt_consult.py, cmd.exe, python.exe) fails 'OSError: [Errno 8] Exec format error'. gpt_consult.py does not catch it and prints a traceback. Check 'ls /proc/sys/fs/binfmt_misc/WSLInterop' before planning on a Codex consult or any Windows build; any agent can fix it without sudo: `/init /mnt/c/Windows/System32/wsl.exe wsl.exe -d Ubuntu -u root -- sh -c "echo ':WSLInterop:M::MZ::/init:PF' > /proc/sys/fs/binfmt_misc/register"` (/init runs a Windows exe directly; its argv[2] is argv[0], so the exe name is repeated). Fixed that way by BENCH 2026-10-25. It went missing right after a helper test-installed and unregistered a second WSL distro on Archmagi (suspected cause, not proven).
