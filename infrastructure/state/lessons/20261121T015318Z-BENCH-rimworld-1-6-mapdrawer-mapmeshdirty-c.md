In RimWorld 1.6, MapDrawer.MapMeshDirty(c, flags) with two arguments dirties the 8 neighbours' sections only when flags include FogOfWar, Buildings or Roofs. A custom flag (RM_WaterLooks) or Terrain alone re-meshes only c's own section, so a neighbour across a section edge keeps a stale mesh. Pass regenAdjacentCells: true. Also: pending re-mesh is layer.Dirty OR the section's untransferred dirtyFlags bits; a proof that calls layer.Regenerate() leaves Dirty set unless it clears it.
