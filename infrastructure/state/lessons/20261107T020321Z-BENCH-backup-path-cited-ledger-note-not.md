A backup path cited in a ledger note is not a durable proof: LIQUIDNET_SURFACEGAP_FIX_UNLANDED_CLONES's 2026-11-01 note names a bundle folder under D:\ClaudeWork\backups\leftovers that was absent by 2026-11-06, so its blob-identity claim could not be rerun and only commit ancestry remained measurable. When dropping a clone, name the main commits that hold its work; treat the bundle as a convenience.
