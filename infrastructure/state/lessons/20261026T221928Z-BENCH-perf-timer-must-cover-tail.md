A per-frame timer that stops before the method's publish tail hides the cost that grows with the map: GSS Rebuild timed snapshot+Build (2-5 ms) while an untimed tail (string union-find + string section signatures over every piece) ran O(map cords) and made ~3.7 MB garbage per frame, feeding Mono's stop-the-world GC (the lone 140 ms slice, GSS_SLICE_FIX_LONE_REBUILD_HITS_140MS, fix 36187e3524). Time the WHOLE method, tag frames a GC.CollectionCount(0) change landed in, and keep a resettable window max beside any lifetime max.
