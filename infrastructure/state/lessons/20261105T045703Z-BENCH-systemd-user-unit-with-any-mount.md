A systemd --user unit with any mount sandboxing (InaccessiblePaths etc.) runs in its own user namespace: readlink /proc/<pid>/cwd of any process outside it fails (own children still read), and no unit property lifts that. So the Marker's box can never see other processes' cwd; read them outside (offbox adapter proc_cwds) and make in-box selftests that walk /proc use a fake one.
