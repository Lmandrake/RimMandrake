A static collection keyed or valued by Things (Dictionary<Thing,...>, HashSet<Pawn>) in a mod outlives the game: loading a save or quitting to menu drops the old Game and Maps WITHOUT despawning anything, so no PostDeSpawn/Release cleanup runs and the static keeps the whole old Map graph alive for the session (and any IsSpawned re-check on the stale entry still says true). Tag the collection with the Current.Game it was filled in and Clear() it on access when Current.Game differs (LanternDeeps RM_CompPooler.SmotheredByNow), or keep the state on a MapComponent/GameComponent instead.
