The art eligibility gate (regen_eligibility.py) recorded a PawnKindDef's flyingAnimationFramePathPrefix as a literal texture path, never expanding it to <prefix>1..<flyingAnimationFrameCount>. Every fill_queue row for a NEW flip-book frame was therefore refused (REFUSED_REGEN 'renamed - X no longer draws it', or 'no def draws this path') even with the prefix wired. Found queuing RM_Shirrel_Flying_1 (SHIRREL_GLIDE_FILL_FLIPBOOK_FRAMES); fixed by expanding the prefix from the same def's FrameCount (no count = no expansion, fail closed), selftest rows plus a mutant that fails 2 of them. A gate refusal naming 'renamed' for a path that was never drawn means the gate cannot see that tag.
