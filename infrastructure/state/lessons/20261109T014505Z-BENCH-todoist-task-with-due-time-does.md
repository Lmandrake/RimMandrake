A Todoist task with a due time does not ring: only an attached reminder does, and the account had 0 reminders (free plan, urgent_reminder_device None). Todoist urgent reminders (iOS 26+, one per task on the free plan) can break Do Not Disturb, but Todoist warns that one created shortly before it fires may not sync to an iPhone.
