A save/load-identical proof on a FRESH world has two vanilla traps. (1) Game.LoadGame with Prefs.PauseOnLoad runs one DoSingleTick after load (decomp rw16 Verse/Game.cs:638), so the loaded arm is +1 tick: compare both arms at the same TicksGame. (2) SurfaceLayer saves each planet tile's base temperature as ushort RoundToInt((t+300)*10) (RimWorld/SurfaceLayer.cs:102,220): a never-saved world keeps the finer worldgen float, so 'deterministic' OutdoorTemperatureAt(tile, absTick) reads ~0.03 C different live vs loaded at the same tick. Only the first save/load of a world shows it, so reruns on one map pass and hide it; test on --fresh-map. Found by emitting the raw pulse-time reading, not its hash (CANAL_OVERFLOW round 4).
