A shared compiled assembly (RimMandrakeFlowWorks.dll: ~36 rebuild commits in 72 h on 2026-11-05) made every FlowWorks live item stale while it waited for the game: preflight's stale_build read another item's rebuild as 'changed since the built commit' and sent a PASSed build to a worker who could only land a no-op commit (SUMP_TAR_FIRE_NETWORK_1, twice). Fix OPS_CHURN_DIAGNOSE_SUMP_GSVT_SSCT: relentless_live.carry moves the game phase to the rebuilding commit when only Assemblies/*.dll|pdb|srchash changed and the build's src/ and live_proofs/ paths are byte-identical at HEAD; any other later change still goes back.
