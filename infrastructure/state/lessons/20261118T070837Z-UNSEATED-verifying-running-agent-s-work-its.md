Verifying a running agent's work in ITS clone can destroy that work: to watch its new test fail on base I stashed maturation.py, copied the test in, then ran `git checkout -- selftest_maturation.py` to clean up — which reverted 283 of the agent's own uncommitted insertions. I only recovered them because I had copied the file to /tmp BEFORE touching anything, and I re-ran the suite afterwards to prove the restore (ALL PASS, 360 insertions intact). Do the red-on-base check in a THROWAWAY clone of the branch, never in the live clone of an agent that is still working; if you must do it in place, copy every file you will touch first and verify the diff stat afterwards. Also tell the agent what you did when you resume it.
