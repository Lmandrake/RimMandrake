The test queue cannot run a proof that needs a PROOF build (RmProofs): worker.py, testq.py and deploy_custom_mods.py deploy only the committed release DLL, and a live-proof line runs after load, too late to swap it. Before briefing a SteveDesktop live proof of a mod whose scenes are proof-build only (Explosive Knockback), check the route exists (RIMMANDRAKE_ROUTE_TESTQ_PROOF_BUILD_JOBS_TO_STEVE).
