Facial Animation (1635901197) reads its race-xenotype skip list ONLY from the player's ModSettings (IgnoreEnableAnimationForRaceXenoTypeListAA). No def, extension or XML hook exists, so an opt-out shipped by a mod must be C#: postfix FacialAnimationModSettings.ShouldDrawRaceXenoType(Pawn), resolved by name (StarWarsRaces does this). The owner's own config is not evidence that players get the same.
