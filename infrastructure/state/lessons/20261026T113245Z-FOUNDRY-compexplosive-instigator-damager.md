RimWorld 1.6 CompExplosive.Detonate does NOT use 'instigator ?? parent': it names the explosion (stored == null || stored.HostileTo(parent.Faction) && parent.Faction != OfPlayer) ? parent : stored, where stored = dinfo.Instigator of the damage that started the wick. A factionless thing (plant, chemfuel stack) is never hostile-to (HostileTo(null faction) is false), so the explosion's instigator is whoever hit it. Any gate keyed on an explosion's instigator def (e.g. an oxidizer/fire-ban exemption) must read the exploding thing, not explosion.instigator. Also: Pawn.Kill relights an attached fire on the corpse with fire.instigator outside the Fire's tick (Pawn.cs:2208). Found reviewing CHILLFIREBAN (CHILLFIREBAN_FIX_DETONATION_INSTIGATOR_SWAP, CHILLFIREBAN_FIX_CORPSE_FIRE_KEEPS_OXIDIZER).
