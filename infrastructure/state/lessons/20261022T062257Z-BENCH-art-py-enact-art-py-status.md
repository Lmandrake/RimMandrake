art.py enact and art.py status do not understand a Graphic_Random folder pool: enact refuses to retire the old single PNG ('a def still draws <texPath>') and status on the pool file says UNMEASURED. Install pool files with art.py install <mod> <texPath>/<name>_a.png <sha> --owner-said, retire the old single via artledger.retire(<full src path>, owner_said=...). Also: a sheet's column A is usually 'IN GAME' — an owner pick of A keeps the current art; check snapshot labels before installing 'set A'.
