A mod-ledger append can print APPENDED in your clone and still be fenced: a newer holder lease granted in another clone (EK run-1794896974, token 13, ~2 min after run-1794896854 got token 11) only shows on merge, and then selftest_modledger_tree reads STALE_TOKEN on your lines. On 'stale token ... this run must stop', stop appending, and delete your own fenced lines with modledger.py delete --mod <Mod> --id <id> (the sanctioned route), never by moving the shard file (it may be tracked).
