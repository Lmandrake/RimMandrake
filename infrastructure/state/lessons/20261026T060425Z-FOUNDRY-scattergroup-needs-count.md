A GenStep_Scatterer subclass (GenStep_ScatterGroup included) with no <count> and no <countPer10kCellsRange> scatters ZERO times and logs nothing (count=-1, range=Zero -> CalculateFinalCount 0). And a ScatterGroup <things> list places floor(eligibleCells/10 * coveredCellsPer10Cells) cells' worth, so a tiny range like 0~0.02 on a 7x7 rect places nothing while still 'succeeding'. For exactly one centred building use <count>1</count> + <spawnAtCenter>. Vanilla Fleshbulbs sets <count>5</count>. Both Lantern Deeps entrances never spawned for this (80c122a7b3).
