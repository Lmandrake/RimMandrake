A drvfs (/mnt/d) read can fail once with ENOMEM (errno 12) on an ordinary file and read whole the next time, under memory pressure (618 kB texture in ArchSmall's RimMandrake.Biomes, 2026-11-24). A hash or scan that turns any OSError into 'no folder' then reports a deployed mod as not deployed; read a transient errno again and name the read error apart from absence.
