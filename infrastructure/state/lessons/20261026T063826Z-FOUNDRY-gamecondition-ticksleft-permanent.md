RimWorld 1.6 trap: GameCondition.TicksLeft on a Permanent condition logs 'Trying to get ticks left of a permanent condition' (ErrorOnce) and returns 360000000. Any code that mirrors or reads another condition's remaining time must check .Permanent first (vanilla Aurora and others are canBePermanent via scenario perma-condition). Also: destroying holdsRoof buildings under a constructed roof (Destroy, any mode) marks the unsupported roof to collapse via Building.DeSpawn -> RoofCollapseCellsFinder.Notify_RoofHolderDespawned; clear roofGrid first if the structure should vanish whole.
