Unity's Mono cannot walk another thread's managed stack: System.Diagnostics.StackTrace(Thread, bool) in the game's mscorlib.dll throws NotImplementedException for any thread but the caller (ilspycmd, 2026-11-03). A stall diagnostic must use breadcrumbs (JawaBenchTpsWatchdog phase stack, JawaBenchStallProbe tick bucket) and native thread CPU, not a stack dump. JawaBenchLoadStallProbe's eventThread stackTrace hits the same wall. (BRIDGE_STALL_DIAGNOSTIC_1)
