Remote-repairable Windows bootstraps must be safe to RERUN over the SSH session they repair. Codex caught three ways a rerun could cut its own door (2026-10-25, SteveDesktop): (1) Set-NetAdapterPowerManagement / Set-NetAdapterAdvancedProperty restart the NIC unless given -NoRestart, so only change values that differ and always pass -NoRestart; (2) an unconditional 'wsl --shutdown' kills the WSL Tailscale door and any job, so restart Ubuntu alone (wsl --terminate Ubuntu) and only when systemd is not PID 1; (3) a -Resume path that skips the reboot gate, or removes the resume task while WSL steps failed, leaves no automatic retry. Also: NoAutoRebootWithLoggedOnUsers is honoured only with AUOptions=4, and Home ignores these policy keys; -AllowComputerToTurnOffDevice is not a Set-NetAdapterPowerManagement parameter (an empty catch hid it).
