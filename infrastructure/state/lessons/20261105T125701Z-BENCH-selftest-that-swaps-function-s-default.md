A selftest that swaps a function's default by POSITION (__defaults__[:-1] + (x,)) breaks silently when the function grows a trailing keyword param: selftest_live_queue turned clockgate.verify_pause's new why=None into a sleep function, the except caught why.append, and all six abort_proof hazards read 'not paused'. Swap defaults by parameter name. Also: known_reds' first_error can quote a suite's INTENDED negative-case FAIL line (here 'FAIL kill: ...' from the no_damage_log sabotage) as the alarm title; read the summary line, not the first FAIL.
