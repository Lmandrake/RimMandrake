Never put a mutate_*_fuzz.py in the same run_selftests --only batch as the fuzz it mutates: the mutator edits the production kernel in place while the parallel fuzz builds from it, so the fuzz reads a planted mutant and goes red on code nobody wrote (measured 2026-11-16, Graffiti: 'misc' red on a Stencil-in-spree mutant). Run the mutator alone. A SIGKILLed mutator's stranded mutant is now restored by the next mutator run (RIMMANDRAKE_RESTORE_KILLED_MUTANTS_SIGKILL_SKIPS_FINALLY, ce417b9d88), not by itself.
