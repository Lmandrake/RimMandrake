Shadow-sheet census files (art_eval_shadow_*.subjects.json, drawbridge_art.subjects.json) store reference_textures / textures_manifest as ABSOLUTE /home/mandrake/rm/bench/... paths, so a sheet rebuilt in any other clone renders bench's files, not its own. Rebuilding a sheet that lives only untracked in bench: rebuild in your clone, pin html+subjects, and copy the byte-identical html + new img/ files into bench before publishing, or bench's seat_sync refuses (a DIFFERENT untracked file where upstream adds one).
