A time-boxed git pass on drvfs that lets git spawn 'maintenance --auto'/gc gets the repack killed with it every time, and each kill leaves a tmp_pack_* in .git/objects/pack: pulse-deploy piled up 284 of them (196.7 GiB), which also slowed every later git status. Set gc.auto=0 and maintenance.auto=false in any checkout a timer updates under a timeout, and check 'git count-objects -vH' size-garbage when such a timer starts timing out.
