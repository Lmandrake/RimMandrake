A DEPLOY_HOLD entry never removes a copy already in the game's Mods tree, and deploy without --prune never removes files whose source moved. Both leave stale defs that load: 2026-10-03 a held TheSump biome + 3 held Foundry/Tibanna files gave 20 dangling cross-refs, and SWBestiary's stale ThingDefs_Abyss.xml (moved to Abyss) named a missing comp type, discarded a def, left a raceless PawnKind and killed AlphaMemes/GeneticRim/BiomeCompat static ctors. A composed Biomes deploy is a separate command (--compose biomes). Clean deploy = plain --apply --prune, then --compose biomes --apply --prune, then delete deployed copies of held paths.
