systemd-run -E NAME with NAME unset in the caller sets NAME='' in the new unit (systemd 259, measured 2026-11-06), it does not skip it. A reader doing env.get(NAME, default) then gets '' not the default: wrapup's seat-clone carry and bridge lock went blind for every role unit (WRAPUP_DEBRIS_FIX_BLAMES_THE_WHOLE_HOUSE). Read handed-on vars with 'env.get(NAME) or default', or scrub empties first.
