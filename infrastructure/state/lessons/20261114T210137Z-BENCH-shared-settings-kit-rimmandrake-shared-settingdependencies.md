The shared settings kit (RimMandrake.Shared.SettingDependencies Declare/Dependent) and PatchFeature(label, type, field) take only BOOL masters: PatchApplier forces a failed patch's field false only when FieldType is bool. Turning a bool setting into an enum (GSS fallenWireShock -> shockReach) means: declare it Independent, gate its patches in the body (label-only PatchFeature), and keep a derived bool mirror if another mod reads the old name. Found 2026-11-14.
