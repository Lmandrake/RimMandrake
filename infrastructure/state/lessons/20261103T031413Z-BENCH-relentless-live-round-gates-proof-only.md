A relentless live round gates a proof only on the mod folders its built sha changed, plus a live-mods: line in infrastructure/state/live_proofs/<ID>.txt. A proof-only or ledger-only build sha changes no folder, so without live-mods the proof runs on whatever load is up and fails as a wrong-load game_fail (TITANIC_BODYSIZE_TEST_RACE_1, 2026-11-02). live-mods can only name folders in the game's Mods dir; a workshop dependency goes in a # note to the stager.
