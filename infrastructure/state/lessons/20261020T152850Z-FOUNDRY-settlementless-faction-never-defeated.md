A RimWorld 1.6 faction with no settlements can never be defeated: Faction.defeated is set only by SettlementDefeatUtility.CheckDefeated when the player takes its LAST settlement, and the engine removes only temporary factions. It still raids, trades and visits, because IncidentWorker_PawnsArrive.MustHaveSettlementOnLayer is false for every vanilla worker. Hidden does NOT stop enemy raids (IncidentWorker_RaidEnemy passes allowHidden:true); raidsForbidden does. To take a faction off the board, banish it (def: hidden + raidsForbidden + canGenerateQuestSites false; save: defeated, world objects removed), never delete it.
