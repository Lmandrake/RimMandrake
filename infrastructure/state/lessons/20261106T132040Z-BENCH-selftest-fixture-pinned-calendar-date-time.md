A selftest fixture pinned to a calendar date is a time bomb when the code under test has an age cutoff (testq fault_monitor RERUN_WITHIN_S=48h turned selftest_testq_fault_monitor red 2 days after writing). Build fixture timestamps relative to time.time(). Also: a NIGHTLY_RED summary quotes a FAIL line the test prints on purpose (check()'s own output), not necessarily the failing assertion — grep 'FAIL  ' (two spaces) in the test output.
