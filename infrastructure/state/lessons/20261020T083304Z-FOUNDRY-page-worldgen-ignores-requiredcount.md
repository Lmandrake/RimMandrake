In 1.6 a world made through the Create World page generates ONLY the page's faction list (FactionGenerator.InitializeFactions with a non-null list). requiredCountAtGameStart is read only on the no-page path (factions == null). A hidden faction must therefore be on the list: maxConfigurableAtWorldCreation > 0 (default -1), startingCountAtWorldCreation > 0, displayInFactionSelection false — the shape of Core's Insect/Ancients. RUT_GreentideAntFaction (start 0, no maxConfigurable) was absent from the 2026-10-20 dev world for exactly this reason; fixed d0601bcd5.
