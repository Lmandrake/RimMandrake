The bridge's safe_advance and step_game_ticks advance time with TickManager PAUSED (DoSingleTick inside paused frames), so any code that treats Paused as 'no tick will pass, rebuild unthrottled' (MapComponentUpdate hooks) runs every stepped frame. On 2026-10-22 RM_WallReach rebuilt ~1 labelling per tick in a stepped soak against a throttle of 8 per 60 ticks. Judge a paused frame by whether TicksGame moved since the last one, never by the Paused flag alone (WALL_REACH_TUNE_REBUILDS_TENFOLD, 0d8b03305).
