When a live check passes on one game and fails on another with the same build, read the mod's own journal lines in BOTH the passing and the failing runs before you blame the site. In sc_pawn_arc every run (pass and fail) journaled resume_skip stack_gone: the mod never gave the haul back, and the pass was free will at a lucky origin. A verdict that free will can satisfy hides a mod gap; make the verdict read the mod's own act (its journal line).
