A delegated art install passes the pre-push art_guard only if --why STARTS with the literal 'delegated: art <verdict file path inside the clone>' (art_guard.delegated_verdict parses the first token as the path). Free text like 'delegated: art-eval flight frames (run X, <path>)' is refused as reason agent-why with no mechanical tag, after art.py install has already succeeded locally. Also art.py install --file refuses a PNG outside the clone: stage it in Transient/ first. (MYNOCK_FLIPBOOK_FRAMES_1, 2026-11-03)
