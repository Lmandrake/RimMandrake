PIL Image.rotate(90*k, expand=False) on a NON-square piece keeps the w x h canvas: the turned piece is cropped to its old width and any paste offset computed from its unturned height lands (h-w)/2 px off. The 2026-10-22 pipe-fittings composer did this to the EndCap, so on 3 of 4 pipe looks the north/south end caps shipped clipped to pipe width and floating 7-10 px clear (PIPE_CAP_FIX_NORTH_END_FLOATS_FREE). Quarter turns of non-square sprites: expand=True or np.rot90. Second half: before pixel-fixing a shipped texture, run art.py status on it; an owner-KEPT picture refuses a mechanical install at pre-push (delegation_policy 3), so build the fix as a script with --out candidates plus an --install that needs his ruling, not as a direct PNG write.
