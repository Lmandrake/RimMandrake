Filtering ThingSetMaker_Meteorite.nonSmoothedMineables is not enough: the private FindRandomMineableDef rolls a bucket first (0.4 non-resource rock, 0.35 ore <5 silver, 0.25 ore >=5) and RandomElement()s inside it, so removing every stone type makes 40% of meteorites pick null and ThingMaker.MakeThing(null) throws. Replace the draw (prefix renormalising over non-empty buckets) and only filter while that prefix is installed. Also: Reset runs from PlayDataLoader.ResetStaticDataPost BEFORE StaticConstructorOnStartup, so a Reset postfix must not touch a [StaticConstructorOnStartup] class.
