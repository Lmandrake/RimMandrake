RimWorld 1.6 GenPlace puts one item per cell (PlaceSpotQualityAt ~L242), so a ThingPlaceMode.Near drop lands OUTSIDE a small radius once items such as stripped gear fill it. Code that later finds its own drop by 'within radius r of the spot' loses it. Remember the Thing you dropped (Scribe_References) instead of searching for it.
