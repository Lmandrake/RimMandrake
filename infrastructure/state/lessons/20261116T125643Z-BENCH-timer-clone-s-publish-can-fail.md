A timer clone's publish can fail forever while every push succeeds: on 2026-11-16 the dispatch clone pushed its ledger lines each tick (replayed tips) yet sat behind 59 for 40 min, because the tick's own uncommitted mod-ledger appends (design/concepts/*/ledger/*.jsonl, not merge=union then) blocked every branch move, and when it had no local commit ingest linted the stale HEAD (an origin commit) and read origin's newer lines as removed. Read 'ledger_lint ... over <sha>' by first asking whether <sha> is already on origin/main; if so the lint is judging a stale HEAD, not bad lines.
