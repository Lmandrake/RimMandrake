A systemd ExecStopPost inherits the unit's StandardOutput=file:<path>, and file: reopens at offset 0 without truncating, so anything the post command prints overwrites the HEAD of the main command's output. wrapup.py unit printed one line and turned every role run's result JSON unparseable (role:Operations:failed 'no result file', 2026-11-04). Post commands on a file:-output unit must print nothing, or the unit must use append:.
