Relentless game mode has no step that WRITES the live world: staging only deploys and restarts, the live round only reruns read-only proofs. An item whose deliverable is a bridge write plus a save (BIG_REPAINT_FINISH_ONCE_AND_FOR_ALL: repaint_stamp.py --apply) can never pass blind; it must be snagged --blocker live with the one command a bridge holder runs. Also: the DefDump that matched a save's mod set can vanish (captures pruned); decode tiles by base shortHash of the defName (repaint_biomes.py --decode-by-name) and cross-check a recorded histogram rather than trusting a mismatched table.
