Stopping timers for a cutover without a scheduled resume kills the no-LLM lanes for hours: on 2026-10-28 05:04 a laptop-seat agent stopped every rm-*/testq-* user timer on Archmagi over Tailscale SSH (list saved to ~/rm/paused-timers-rewrite-20261028.txt) and nothing restarted them until 09:41; every watchdog (deadman, ops-watch, steward-watch) was inside the stopped glob. Pause timers only with a resume armed in the same command (systemd-run --user --on-active=6h systemctl --user start $(cat list)), and to find who stopped a unit read the system journal's tailscaled 'starting non-pty command' lines, which carry the full remote command.
