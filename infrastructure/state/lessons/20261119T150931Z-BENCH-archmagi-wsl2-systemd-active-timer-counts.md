On Archmagi (WSL2) a systemd --on-active timer counts monotonic time, which falls behind the wall clock in bursts: a 30 s timer fired 58.8 s late and a 90 s one 141 s late, while an --on-calendar timer set beside it fired 0.05 s late (2026-11-19). A deadline told to a person or agent as a clock time must be an --on-calendar timer. seat_restart.py still uses --on-active for its delayed start [unchecked].
