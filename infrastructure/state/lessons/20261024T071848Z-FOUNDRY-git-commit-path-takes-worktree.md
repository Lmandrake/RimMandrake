`git commit -- <path>` (and `git commit <path>`) commits the WORKING-TREE content of the path and ignores what you staged with update-index or add. In a file another helper is editing, that sweeps their uncommitted hunks into your commit. A house hook refuses `git commit` with no pathspec, so you cannot commit only your hunks directly. What worked: commit with the pathspec, then build HEAD~ plus your hunks as a blob, `git hash-object -w` it, `git update-index --cacheinfo 100644,<sha>,<path>`, and `git commit --amend --no-edit` (allowed). Verify with `git show HEAD`, and check that the peer's hunks are back in `git diff`. Cleaner still: leave the shared file to its other editor, or wait until they commit. 2026-10-24, proof_atmosphere.py, caught before publish and amended.
