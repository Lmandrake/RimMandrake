RM_MapComponent_Hoses.CellChanged marks a cell dirty only when CordSig.CellSig differs, and CellSig (CordWorld.cs:352) omits BlockKind; so a direct swap between two blocked kinds (Rock<->Wall, Wall<->Device) is never patched and the hose world keeps the stale BlockAt, which CordPlanner reads into InKind/OutKind. The offline replay harness (HOSE_PERF_BUILD_OFFLINE_REPLAY_HARNESS) caught it as patch-gate RED when a generated wall rect landed on rock. Normal play reaches such a swap only via an intermediate walkable state (mine, then build), so it is latent, not live; the production patch probe (RM_MapComponent_Hoses ~line 1225) would flag it too. Fix if ever reachable: fold BlockKind into CellSig or compare BlockAt in CellChanged.
