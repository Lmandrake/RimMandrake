A folder-hash cache keyed on each file's path, size and mtime reuses a stale hash: a same-size rewrite with its mtime put back (utime) misses nothing, and two folders with equal names/sizes/mtimes share one entry. Key on the folder's realpath plus each file's st_ctime_ns too (a write moves ctime and no utime can restore it; measured on drvfs 2026-11-17). os.walk by default skips linked directories and swallows unreadable ones (no onerror), so a hash silently drops part of the folder; walk with scandir, follow links once per real dir, and let OSError make the hash unreadable. On /mnt/c, os.path.realpath on every directory made a 4761-file walk 81 s against 11 s resolving links only. Found by a GPT review of build_match.py (conductor/bm_gpt_review.md).
