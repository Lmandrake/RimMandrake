relentless_seeds.py run killed by a foreground timeout leaves its rm-seedcheck-* unit running: the next run refuses ('a seed check is still running') and the orphan's verdict is never collected. Stop the unit with systemctl --user stop <unit>, then rerun (resumable). Keep --limit x case time under the timeout (3 workers x ~60-150 s per case: --limit 6 per 540 s call is safe, 9 is not).
