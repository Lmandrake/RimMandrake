On drvfs (/mnt/c, /mnt/d) a directory reached by another spelling of its case is the same directory, but os.path.realpath keeps the spelling, so a walk that cuts link cycles by real-path string hashes a link back to an ancestor (BmCase/self -> bmcase) once more. Know a directory by (st_dev, st_ino): measured equal across case on /mnt/d 2026-11-17. The fix costs a stat per directory (RimMandrake.Biomes walk 11.7 s -> 21.8 s). In the same review: a cache key that joins names with newlines collides, because a name may hold a newline (serialize each part as JSON); and a /proc file reads bytes at stat size 0, so a hash must refuse any file whose read length is not its size before a metadata-keyed cache can be trusted.
