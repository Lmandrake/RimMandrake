Committing only YOUR hunk of a shared file whose worktree also holds a peer's uncommitted line: 'git commit <path>' takes the whole worktree file (peer line included) and a pathspec-less commit is hook-blocked. Build the blob (HEAD + your line), then commit through a private index: GIT_INDEX_FILE=tmp git read-tree HEAD; git update-index --cacheinfo 100644,<blob>,<path>; git commit-tree $(git write-tree) -p HEAD; git update-ref refs/heads/main <new> <old>. Also: a 'git commit -- paths' leaves any OTHER staged path still staged (seen 2026-10-23, csproj with peer's RM_PipeSeatMath.cs line).
