To run a world-authoring script on a canonical save (R3, the REPAINT start), load a byte copy of it under another name. With the canonical name loaded, the companion runs CAMPAIGN and refuses the heavy-diagnostic tools, jawa/world_mutators_audit included, so a stamp script with a mutators-audit readback bar stops after its world_commit, with nothing saved. R3's own 325-mod list also names 7 ids that are not installed, so its load needs ignoreModCompatibility:true.
