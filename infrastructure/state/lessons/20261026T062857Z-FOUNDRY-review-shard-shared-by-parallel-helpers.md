Two review helpers in one seat both mark-clean into the same shard (infrastructure/state/code_review/<SEAT>.jsonl). The commit hook demands a pathspec commit, which takes the whole worktree file, so neither helper can commit its own records without sweeping the other's uncommitted marks. A blob built from HEAD plus only your lines can be staged with update-index, but a pathspec-less commit is refused, so even that does not work. Fix options: one shard per helper/session, or a code_review_status.py 'commit-mine' verb that commits only records carrying the caller's tag. Until then: the helper that commits last sweeps both, or the parent commits the shard once both are done.
