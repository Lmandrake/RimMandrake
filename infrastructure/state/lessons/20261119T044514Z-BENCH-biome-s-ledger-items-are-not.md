A biome's ledger items are not all filed under its current name: the Abyss's first items are FORSAKENCRAGS_*, FORSAKEN_CRAGS_* and LIGHTFALL_*, and a search for ABYSS in infrastructure/state/items misses them. Before calling a biome's items read, search every name the biome has had (the rename item lists them). And 'mentions elsewhere in design/' is not a readable set: for the Abyss it is 286 files and 22 MB, mostly registers; a brief that wants every source read to its end has to bound that set or the answer can never be yes.
