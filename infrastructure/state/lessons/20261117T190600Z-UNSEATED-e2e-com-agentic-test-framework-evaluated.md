e2e.com (agentic test framework) evaluated for the pipeline 2026-11-17: its replay cache is route-keyed ('the starting screen must be the same route'), so it cannot apply to RimWorld, whose quicktest maps re-roll every run and whose canonical save freezes a START, not a trajectory. A cache that always misses costs the model call PLUS the replay attempt. Import its three RULES instead, which need no dependency: (1) a finding is a bug only when its test fails for the reported reason; (2) an unverified success is deleted, not recorded as UNMEASURED ('unconfirmed, therefore not saved'); (3) budgets are per-step and enforced by the runner, exceeding them is an error code, not the spending agent's judgment.
