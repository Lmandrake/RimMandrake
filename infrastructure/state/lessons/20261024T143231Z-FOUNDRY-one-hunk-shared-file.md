To commit only your hunk of a file another helper is also editing (pathless git commit is blocked; git commit <path> takes the whole working file), build the commit in a private index: GIT_INDEX_FILE=tmp git read-tree HEAD; GIT_INDEX_FILE=tmp git apply --cached --recount my.patch; git commit-tree $(GIT_INDEX_FILE=tmp git write-tree) -p HEAD; git update-ref HEAD <new> <old>; then git restore --staged <path> so the shared index matches the new HEAD. Used 2026-10-24 for the Mullgoth alternateGraphics hunk of RSW_DesertPortMisc_Races.xml beside the in-flight Chikka move. Also: in zsh a $P string of paths is not word-split; use an array.
